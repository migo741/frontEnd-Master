# 第 10 章：字体、排版与国际化

## 排版首先服务阅读和任务

正文可读性由 font family、size、line-height、measure、weight、字距、段落节奏共同决定。不要用固定 16px/24px 当普遍答案；以语言、字体、密度和用户缩放验证。正文常用 45～75 字符量级的 measure，但中文、代码和数据表不同。

`rem` 让用户字号偏好进入系统；标题可用 `clamp()` 流体变化，但不能覆盖语义层级。`text-wrap: balance` 适合短标题，不适合长正文；`pretty` 可改善段落尾行但仍需兼容检查。

## Web Font 与稳定性

字体会阻塞或替换文本，导致 FOIT/FOUT 与 CLS。只加载必要字重/字符，合理 preload，使用 `font-display`，为 fallback 通过 `size-adjust`、ascent/descent/line-gap overrides 匹配指标。不要为了消除闪动隐藏文字。

Variable font 减少多个文件并提供轴，但文件不一定总更小；按实际 subset 与压缩结果判断。

## 国际化不是翻译后再修

使用 logical properties 与 `dir`，不要把 left/right 写进通用组件 API。处理 CJK 断行、长德文、无空格 URL、阿拉伯 RTL、数字/金额对齐。视觉重排不能破坏 DOM 阅读顺序。图标如“前进箭头”可能需要 RTL 翻转，品牌 logo 不应翻转。
