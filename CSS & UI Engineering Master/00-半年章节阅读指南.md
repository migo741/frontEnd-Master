# 半年章节阅读指南｜CSS & UI Engineering

> 本课预算：35 小时。课程篇幅短但实践性强；A 章要直接作用于统一 SaaS 界面，前沿 API 和独立毕业项目降低深度。

等级规则：`A` 是生产 UI 必学；`B` 优先建立能力并按需实现；`C` 不另建项目，只复用验收表。

## 不可削减的验收线

- 320px 到宽屏、200%/400% 缩放仍能完成任务；
- 键盘与可见焦点完整，强制色和 reduced motion 可用；
- 不靠随机 z-index、固定高度和 `!important` 修事故；
- 新 CSS API 只提供增强，不承担业务正确性；
- 视觉回归基线必须人工审差异，不能盲目更新快照。

若时间不足，先把 07、10、11、13 变成只读；01～06、09、14～17 继续实践。
