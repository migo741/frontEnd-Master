# 练习：用 CSS 表达视觉状态但不隐藏业务状态

## 题 1（50 分钟）

用 `:has()` 实现三种父级视觉：含用户错误的 field group、含当前页面的导航 section、选中 checkbox 的 table row。不得用 JS 添加纯视觉父 class；必须限制匹配范围并为错误/选中提供原生语义。

验收：去掉 CSS 后功能和状态仍可理解；写出不支持 `:has()` 时的可用基础表现。

## 题 2（60 分钟）

把 Sass 风格六层嵌套组件重写为原生 Nesting + 低权重 public API，并用 `@scope` 渐进增强一个文章区域。常规选择器不高于 `0-3-0`；关闭 `@scope` 后不得污染页面其他组件。
