# 第 07 章：现代选择器、嵌套与作用域

## 选择器表达关系，不替代语义

`:is()` 合并候选，`:where()` 建立零权重基础，`:not()` 排除，`:has()` 根据后代/兄弟状态选择当前元素。它们能减少仅为样式添加的 JS class，但不应把整个业务状态机藏进 selector。

```css
.field:has(:user-invalid) { --field-border: var(--color-danger); }
.row:has(> [aria-selected="true"]) { background: var(--selection-bg); }
```

`:has()` 参数应限制在组件局部，避免难读的全页面深层关系。`:user-invalid` 通常比 `:invalid` 更适合用户交互后的错误表现，但仍要有文本错误与语义关联，颜色不是验证系统。

## 原生 Nesting

CSS nesting 已是现代生产能力，但与 Sass 历史语法并不完全相同。`&` 表示父规则，嵌套 selector 的权重行为接近 `:is()` 组合。嵌套建议最多 2～3 层；深层嵌套会重新制造 DOM 耦合和权重传播。

```css
.card {
  padding: var(--space-4);
  &:hover { border-color: var(--border-hover); }
  & > .card__title { margin: 0; }
}
```

## @scope

`@scope` 可定义 scoping root 和 limit，并引入 scope proximity；截至本课程基线它属于新近可用能力，旧企业浏览器不能默认支持。当前没有一个可普遍依赖的直接 `@supports` 条件来检测整个 `@scope` at-rule；正确策略是先用 layer/类名建立基础边界，再把 `@scope` 作为可被旧浏览器整段忽略的增强。不要把它与 Shadow DOM 隔离混为一谈。

## 选择器性能

现代浏览器对常见 selector 很快。优先优化可维护性；只有 Performance trace 证明 style recalculation 是瓶颈，再缩小高频动态子树的匹配范围。昂贵的根因常是 DOM 巨大且状态频繁改变，不是“用了一个属性选择器”。
