# 第 05 章：Grid 与 Subgrid 二维布局

## Grid 显式描述轨道关系

Grid 同时管理行列。先区分 explicit grid 与 implicit grid，再理解 track sizing：固定长度、百分比、auto、min/max-content、`minmax()`、`fr`。`1fr` 分的是剩余空间，默认仍尊重 item 的自动最小尺寸，因此生产代码常见 `minmax(0, 1fr)`。

```css
.cards {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(min(100%, 18rem), 1fr));
}
```

`auto-fit` 会折叠空轨道，让现有项扩展；`auto-fill` 保留潜在空轨道。不要死记结论，通过是否希望空槽占空间选择。

## Subgrid 解决嵌套对齐

普通子 Grid 会建立自己的轨道，卡片标题/正文/按钮难以跨卡片对齐。子项使用 `grid-template-rows: subgrid` 可以继承父级轨道线。它适合表单、卡片集合等共享结构；如果每个组件内容关系独立，不应为了视觉一致强行 subgrid。

## 自动放置与语义

`grid-auto-flow:dense` 可视觉填洞，但可能改变视觉顺序而不改变 DOM/焦点顺序，交互内容应谨慎。Grid areas 能清晰表达 App Shell，但窄屏重排仍须保证阅读与焦点顺序一致。
