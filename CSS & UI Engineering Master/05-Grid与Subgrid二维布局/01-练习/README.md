# 练习：动态 Dashboard 与对齐表单

## 题 1（60 分钟）

实现未知数量 KPI 卡片：容器足够时自动增列，最窄卡片保持可读；卡片标题、数值、趋势和操作跨卡片对齐。只允许一个真正的结构断点，不为卡片数量写条件。

要求使用 Grid + Subgrid，并给不支持 subgrid 时不破坏阅读的 fallback。

## 题 2（60 分钟）

实现设置页：section 导航、表单主区、帮助侧栏；字段由数据动态生成，label、控件、说明、错误跨行对齐。窄容器变单列，DOM 顺序必须与阅读顺序一致。

验收：长标签、两行错误、隐藏帮助栏、RTL 和 200% 缩放都不破版。
