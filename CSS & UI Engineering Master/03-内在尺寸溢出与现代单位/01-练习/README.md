# 练习：未知内容压力测试

## 题 1（60 分钟）

实现用户卡片：头像、姓名、邮箱、角色 badge 和操作按钮。输入包含 200 字符 URL、德语长词、中文、emoji、缺失头像和 8 个 badge。240px 容器与 200% 文字缩放下不得产生页面级横向滚动。

要求明确哪些信息换行、哪些局部截断以及完整值如何访问；不能给卡片固定高度。

## 题 2（45 分钟）

修复移动端 SaaS 登录页：地址栏变化时底部按钮跳动/被遮挡，键盘打开后内容不可达，iPhone 安全区压住操作。使用现代视口单位、safe-area 和内容尺寸约束，并给旧浏览器基础 fallback。
