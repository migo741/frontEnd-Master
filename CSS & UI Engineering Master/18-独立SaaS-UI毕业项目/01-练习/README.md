# 练习：从设计规格到生产加固

## 题 1（2 周）

完成 NomadOps 多主题后台。第一天只交信息层级、DOM/焦点顺序、token、layout contracts 和状态矩阵；确认后才写视觉。禁止使用完整 UI 组件库替代核心题目，可以使用图标和无样式 headless primitive。

验收：讲义中的 8 类证据全部提交；关键路径可在断网 fixture 中运行；所有视觉状态可通过独立 URL/story 复现。

## 题 2（2 天压力测试）

第一版完成后加入变更包：阿拉伯 RTL、新租户品牌、compact density、最长德文、400% zoom、280px 嵌入容器、第三方日期控件、关闭 View Transition 支持。不得复制整套页面或改业务 DOM 规避。

提交重构报告：哪些设计扛住变化，哪些技术债暴露，如何渐进迁移和回滚。
