# 第 17 章：Vue/React 集成、兼容与视觉回归

## 框架不会改变 CSS 的底层规则

Vue scoped CSS 通过编译后的属性 selector 限定匹配；slot/子组件/Teleport 仍有特殊边界。React CSS Modules 产生局部 class 名，但全局 tokens、element defaults 和 portals 仍参与 cascade。Tailwind/utility 是声明组织方式，不会消除 intrinsic sizing、stacking context 或 accessibility 问题。

SSR 常见故障包括样式抽取顺序不同、重复注入、主题 hydration 不一致、FOUC 和 CSP 阻止内联初始化。样式 order 应由 layer 保证核心语义，不依赖 chunk 到达先后。

## 渐进增强与兼容

建立 browser matrix：用户占比、企业设备、WebView、无障碍环境。先写可用基础，再在 `@supports` 增强。Autoprefixer 只处理部分语法前缀；polyfill 也可能增加 JS/运行时成本。CSS 新 API 的子能力支持需逐项检查。

## 视觉回归

视觉测试适合捕获布局、主题和状态组合变化，不能判断业务正确或读屏体验。矩阵至少包含 component/page、viewport、theme、locale、density、interaction state；多浏览器按风险选择。固定字体、动画、时区和数据，mask 真正动态区域。任何更新 baseline 都要人工审查。

Story/fixture 应覆盖 default 之外的 loading/empty/error/long text/RTL/forced-colors。截图全部 happy path 会制造虚假信心。
