# 练习：样式边界与多浏览器门禁

## 题 1（75 分钟）

修复一个 Vue/React 混合案例：Vue scoped 深层覆盖第三方 DOM、Teleport 弹层无样式、React portal 主题丢失、SSR 首屏主题闪烁。建立 token/layer/module/public API 边界，禁止依赖第三方内部 nth-child。

## 题 2（90 分钟）

为 Button、Form、Dialog、DataTable 和完整 Dashboard 建立 Playwright 视觉回归。覆盖 Chromium/Firefox/WebKit、320/768/1440、light/dark、长文本/RTL、reduced motion；定义 baseline 审批流程。

验收：故意制造层叠、字体、sticky 和主题回归，测试能稳定发现；不能通过提高全局容差隐藏。
