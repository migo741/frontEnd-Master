# 第 06 章：响应式与容器查询

## 响应式不是设备型号清单

从内容约束出发：何时文本行太长、操作挤压、并列关系失去意义，再设断点。mobile-first 不是先做一张手机稿，而是让基础 flow 在最受限空间可用，再用 min-width 增强。

Media query 适合 viewport、输入能力、用户偏好、打印等环境。Container query 适合同一组件在主栏、侧栏、弹窗中复用：组件只依赖自己获得的空间，不认识宿主页面。

```css
.card-host { container: card / inline-size; }

@container card (width > 32rem) {
  .card { grid-template-columns: auto 1fr auto; }
}
```

命名 container 防止嵌套时匹配错误祖先。设置 size containment 会影响尺寸贡献，要优先 `container-type:inline-size`，并验证父布局。Container style queries 和更多新语法在 2026 仍属互操作推进项，应做增强而非关键依赖。

## Intrinsic responsiveness

许多布局不需要断点：`auto-fit + minmax`、Flex wrap、`clamp` 和自然 flow 能连续适应。断点数量越多越不高级；但为了键盘任务顺序、导航结构或复杂表格切换表现，明确断点仍是正确工具。

同时测试宽度以外的条件：hover/pointer、orientation、prefers-reduced-motion、prefers-contrast、forced-colors、print。不要用 hover 是否存在推断用户一定使用鼠标。
