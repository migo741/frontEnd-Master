# 练习：真正可嵌入的 SaaS 卡片

## 题 1（60 分钟）

同一个订单摘要组件分别放进 260px 侧栏、480px Drawer、820px 主区。基础布局为列表，空间足够后增强为表格式列对齐。不得使用 viewport media query、宿主 class 或复制 DOM。

验收：嵌套在另一个 container 内仍匹配正确；关闭 container query 后基础布局可完成任务。

## 题 2（45 分钟）

构建 SaaS Hero：标题、说明、两个 CTA、客户指标和产品截图。在 320～2560px 连续变化，字号/间距使用 `clamp()`，文本行不过宽；最多两个结构断点，并说明每个断点来自哪项内容约束。
