# 第 15 章：无障碍、缩放与极端环境

## 无障碍是约束测试，不是最后打补丁

CSS 可让正确语义变得不可用：隐藏焦点、视觉重排、固定高度剪字、颜色对比不足、hover-only 操作、缩放后二维滚动。WCAG 自动工具只能发现部分问题，必须键盘、缩放、读屏、强制色和触摸人工验证。

## Reflow 与文字缩放

在 320 CSS px 等效宽度/400% zoom 下，除真正二维内容外，不应要求同时横纵滚动。避免固定宽高、`white-space:nowrap`、绝对定位正文。文本行高尽量无单位；容器使用 min/max 与自然增长。浏览器 zoom 与只增大文字会触发不同故障，两者都测试。

## 焦点和顺序

DOM 顺序承担阅读、键盘和无 CSS 的逻辑。Flex `order`、Grid areas 只能在不破坏任务顺序时视觉重排。focus indicator 要有足够面积/对比、不被 overflow 裁切；hover 内容也须能通过 focus/touch 获得。

## 用户环境

- forced-colors：让系统颜色接管，保留 border/outline/文本状态。
- reduced-motion：移除非必要位移/循环，保持状态反馈。
- prefers-contrast：可增强边界，但不是 forced-colors 的替代。
- pointer/hover：增强命中区域，不能假定设备只有一种输入。
- print：关键文档隐藏无关导航、展开内容、显示链接/状态，不依赖背景色。
