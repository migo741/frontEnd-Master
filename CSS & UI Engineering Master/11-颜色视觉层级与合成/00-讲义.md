# 第 11 章：颜色、视觉层级与合成

## 颜色系统要表达关系

使用 OKLCH 更容易按感知亮度和色度组织色阶；`color-mix()` 可从语义色生成透明/混合状态，但每个生成结果仍需实测对比。颜色空间先进不等于自动可访问。

视觉层级来自排版、空间、边界、色差和位置共同作用。不要给所有卡片同样阴影、边框、标题重量，让所有内容同等抢眼。暗色主题不是把 RGB 反转：深色 surface 的层级、饱和度、阴影和图片都要重新评估。

## 合成与效果

opacity 作用整个元素及后代，不等于只给背景透明；应使用 alpha color。filter、backdrop-filter、mix-blend-mode 会创建 stacking context、增加绘制成本并受底色影响。毛玻璃是增强，不应承担信息分隔的唯一责任。

渐变、mask、clip-path、SVG 能创建视觉，但需提供 forced-colors、打印和低性能设备下的可靠结构。图标使用 `currentColor` 易于继承主题；装饰图标隐藏于辅助技术，图标按钮必须有可访问名称。

## 数据颜色

状态色和图表色不只靠 hue；加入文本、形状、线型、图案或位置。检查色觉差异和暗色主题。颜色 token 应按用途命名，而不是 `green-success` 把表现写进语义。
