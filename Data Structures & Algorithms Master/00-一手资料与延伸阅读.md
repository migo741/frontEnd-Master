# 一手资料与延伸阅读

> 这些资料用于核对语言语义、运行时边界和生产结构，不要求从头背诵。先完成对应章节，再带着具体问题查阅。

## JavaScript / TypeScript 语义

- [ECMAScript：Keyed Collections（Map/Set）](https://tc39.es/ecma262/multipage/keyed-collections.html)：相等语义、迭代与规范性能边界。用于第 05 章。
- [ECMAScript：Array.prototype.sort](https://tc39.es/ecma262/multipage/indexed-collections.html#sec-array.prototype.sort)：稳定排序与比较器语义。用于第 07 章。
- [MDN：Intl.Segmenter](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Intl/Segmenter)：按用户可见文本片段分段，理解 code unit/code point/grapheme 的区别。用于第 02 章。
- [TypeScript：strict 选项](https://www.typescriptlang.org/tsconfig/strict.html)：本课程代码的类型检查基线。

## JavaScript 运行时与 CPU 工作

- [V8：Fast properties](https://v8.dev/blog/fast-properties)：对象属性、elements 与引擎内部表示。不要把它误读成跨引擎 API 保证。
- [V8：Elements kinds](https://v8.dev/blog/elements-kinds)：packed/holey 与数组表示，只在 profile 证明需要时做引擎级优化。
- [Node.js：不要阻塞事件循环](https://nodejs.org/en/learn/asynchronous-work/dont-block-the-event-loop)：算法复杂度怎样影响服务公平与吞吐。
- [Node.js：worker_threads](https://nodejs.org/api/worker_threads.html)：CPU 密集工作如何离开主事件循环；Worker 不会自动修复坏算法或取消语义。

## 生产索引与概率结构

- [PostgreSQL：Indexes](https://www.postgresql.org/docs/current/indexes.html)：B-tree、Hash、GiST、SP-GiST、GIN、BRIN 的真实数据库边界。用于第 09、15 章延伸。
- [Redis：Data types](https://redis.io/docs/latest/develop/data-types/)：Set、Sorted Set、Stream 等生产数据结构接口。
- [Redis：Probabilistic data types](https://redis.io/docs/latest/develop/data-types/probabilistic/)：Bloom、Count-Min Sketch、HyperLogLog、Top-K、t-digest。用于第 19 章延伸。

## 源码与系统映射

- [Vue core renderer 源码](https://github.com/vuejs/core/blob/main/packages/runtime-core/src/renderer.ts)：可在完成数组、Map、最长递增子序列等基础后，追踪 keyed diff 的真实工程使用。不要先背源码结论。
- [MIT OpenCourseWare 6.006](https://ocw.mit.edu/courses/6-006-introduction-to-algorithms-fall-2011/)：算法分析、结构与证明的系统补充。课程版本较老，但基础原理稳定。

## 查资料的正确问题

不要只搜“最快的数据结构”。带上：数据规模、读写比例、顺序要求、精确/近似、内存与延迟预算、更新方式、失败模型、语言运行时。看到性能结论时继续问：它是规范保证、某个实现的期望、摊还证明，还是一次特定机器的 benchmark？
