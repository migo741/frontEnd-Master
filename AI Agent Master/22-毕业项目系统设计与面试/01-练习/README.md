# 第 22 章练习

## 练习一：完成毕业项目

按讲义实现 Enterprise Operations Copilot。提交源码、150+ eval dataset、测试报告、trace/dashboard、8 份 ADR、威胁模型、10 份 runbook、部署/回滚和 15 分钟演示。

演示必须包含：正常 run；RAG 引用；人工审批；中途 worker crash 后恢复；重复消息不重复退款；恶意文档注入被阻断；跨租户失败；provider 429 降级；坏 Prompt canary 回滚；成本优化前后。

## 练习二：高级面试与系统设计

再随机回答讲义 22 题中的 10 题并录音。回答后逐项标：是否给失败场景、控制点、验证、取舍；最低两项回炉对应章节后一周重测。
