# 学习方法、环境与版本策略

## 一、你的最短路线

你已有 JS/TS/Vue 基础，所以 Python 部分采用对照式学习：关注 Python 的语义差异、动态数据模型、typing、async 和工程工具，不重复讲“变量是什么”。前 4 章约 30–45 小时，完成后立即进入 Agent。

## 二、建议总投入

### 标准路线：26 周

- 每周 10–14 小时，约 260–360 小时。
- Python 4 周；Agent 原理 7 周；RAG/编排 7 周；生产与毕业项目 8 周。

### 冲刺路线：16 周

- 每周 20–25 小时。
- 每章练习一独立做；练习二先设计再看答案；毕业项目不可跳过。

## 三、环境基线

建议：

```text
Python 3.13.x
uv + pyproject.toml
Ruff（lint + format）
Pyright（主静态检查）或 mypy
pytest + pytest-asyncio/anyio
Pydantic v2 + FastAPI
Docker + PostgreSQL + Redis
```

CI 加 Python 3.12/3.14 兼容 job。不要把全局 Python、系统 pip 和项目依赖混在一起。

示例项目规则：

```toml
[project]
requires-python = ">=3.12,<3.15"

[tool.pyright]
typeCheckingMode = "strict"

[tool.ruff]
line-length = 100
```

每次学习开始先记录 `python --version`、lockfile 和关键框架版本；文稿讲稳定概念，具体 API 以该版本官方文档为准。

## 四、为什么主线不是最新 Python 3.14

调研日官方稳定文档是 Python 3.14.6，3.15 仍是预发布。生产 Agent 依赖很多 SDK、数据库驱动和可观测插件；课程选择 3.13 作为主线，既使用现代类型/async 能力，也减少最新解释器兼容噪音。练习会在 3.14 CI 暴露注解运行时等变化。

参考：[Python 3.14 What's New](https://docs.python.org/3.14/whatsnew/)、[Python Packaging Guide](https://packaging.python.org/en/latest/guides/writing-pyproject-toml/)。

## 五、每章学习循环

1. 用 45–90 分钟读讲义，写下三个“不保证”。
2. 先写测试或 eval，再做练习一。
3. 记录一次失败 trace，不只保存成功截图。
4. 做完再开答案；比较设计边界，而不是逐行抄。
5. 关答案，复写 agent loop/状态图/安全策略。
6. 把本章一个能力合并进持续毕业项目。

## 六、三种验证必须并存

- 确定性测试：工具、Schema、状态迁移、权限、幂等。
- Agent eval：任务完成率、轨迹、工具选择、引用、拒答和安全。
- 线上观测：延迟、成本、失败、人工接管、用户结果与漂移。

“我试了 5 次都挺好”不是质量证据。

## 七、不要被模型供应商绑死

定义自己的窄接口：模型能力、结构化输出、tool calling、stream、usage、错误。不要强行抹平所有供应商差异；能力矩阵显式记录。模型升级必须跑相同 eval 数据集，比较质量、延迟、成本和安全，不按榜单直接切生产。

## 八、框架学习顺序

1. 原生 HTTP/官方 SDK + 手写 loop。
2. LangGraph：显式状态图、checkpoint、HITL、durability。
3. OpenAI Agents SDK：tools、handoffs、guardrails、tracing。
4. 快速比较 PydanticAI、Google ADK、Claude Agent SDK，能读懂即可。

框架的价值是工程能力，不是替你思考业务状态与安全边界。

## 九、成本纪律

- 开发默认使用小模型和录制的 deterministic fixtures。
- 真模型 eval 设每日预算、样本上限和缓存策略。
- 每次运行记录 model、prompt/version、token、latency、tool calls、result。
- 禁止把 API key 写进源码、日志、Notebook 或答案文件。

## 十、安全纪律

- 外部网页、邮件、PDF、RAG 文档和工具输出一律是不可信数据。
- Prompt 不执行授权；工具层验证身份、scope、参数和业务规则。
- 写操作默认需批准；重复执行必须幂等。
- 代码、Shell、浏览器和文件工具在隔离环境运行，限制网络、CPU、内存、时间和文件范围。
- 测试数据不使用真实客户 PII。

## 十一、练习仓库建议

```text
agent-lab/
  pyproject.toml
  src/agent_lab/
    domain/
    models/
    tools/
    workflows/
    rag/
    evals/
    api/
  tests/
    unit/
    contract/
    eval/
    security/
  datasets/
  prompts/
  infra/
  docs/adr/
```

不要把所有逻辑塞进一个 Notebook。Notebook 用于探索，生产代码进入 package、tests 和 CI。

## 十二、毕业判定

- 随机给一个业务任务，能判断普通代码、workflow、single-agent、multi-agent 哪个更合适。
- 能从 trace 定位是模型、检索、工具、状态、权限还是产品问题。
- 能用数据证明一次优化，而非只改 Prompt。
- 能展示失败恢复、安全审批、评测门禁和成本预算。
- 能在 60 分钟系统设计中讲清数据流、信任边界、SLO、回滚和演进。
