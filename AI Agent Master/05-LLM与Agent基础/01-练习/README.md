# 第 05 章练习

## 练习一：Agent 适用性评审

评审 8 个需求：发票字段抽取、固定审批流、跨系统差旅预订、知识库问答、SQL 报表、代码修复、客服退款、定时数据同步。

对每项决定普通代码/workflow/single-agent/multi-agent，写：不确定性来源、工具和权限、停止条件、失败降级、评测指标。至少有两个需求明确拒绝使用 Agent。

## 练习二：运行预算状态机

设计框架无关的 RunBudget：turn/tool/token/cost/deadline/重复动作/无进展。给出正常完成、部分完成、等待批准、预算耗尽、用户取消、系统失败六类终态，以及对用户与内部 trace 的不同信息。
