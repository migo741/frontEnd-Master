# 第 20 章：生产架构、部署与运维

## 本章目标

把 Agent 从 Notebook/Demo 变为多实例、可恢复、可灰度、可降级的服务，并能估算容量与处理事故。

## 1. 参考架构

```text
Web/Client → API/Auth → Run Service → Queue → Agent Workers
                         ↓              ↓
                    Postgres/Event   Model/Tool/RAG
                         ↓              ↓
                    SSE Gateway     External Systems
                         ↘ Telemetry/Eval pipeline
```

API 提交/查询/取消，worker 执行长任务；状态持久化，事件供 SSE/审计。不要把长 Agent 绑在反向代理单请求上。

## 2. 数据存储

PostgreSQL：run/state/event/approval/outbox；Redis：短期 cache/rate/pubsub（不做唯一事实源）；object store：大 artifact；vector/search：知识索引。每层 tenant/retention/encryption。

## 3. Queue 与 worker

at-least-once delivery，visibility/lease、dead letter、优先级、tenant fairness、backpressure。worker 幂等 claim/step，graceful shutdown。消息只放 ids，不放大 Prompt/secret。

## 4. API

submit 返回 run id；status 有 version/terminal/partial；events 可重连；cancel 是 intent；approve 强认证并绑定 proposal。使用 idempotency key 防用户重复提交。

## 5. 配置和 secret

启动时验证 config；model/prompt/workflow/tool policy 可版本化，但危险动态配置需审核/灰度。secret manager、短期凭证、轮换。环境变量不进入 debug endpoint。

## 6. 部署

容器固定 image digest、非 root、read-only；migrations 向后兼容。滚动升级时旧/新 worker 都能读取已有 run，或按 workflow version 路由。readiness 在依赖/停止接单时正确。

## 7. 灰度与回滚

模型/Prompt/工具/graph 分别版本。shadow 先观测无副作用；canary 少量 tenant；eval 和线上 guardrail；出现安全/成本/质量回归独立回滚对应版本。写工具可单独 kill。

## 8. 降级

provider 故障：切兼容模型、队列等待或返回受限功能；RAG 故障：不编造，提示无证据；写工具故障：保存 proposal/人工处理；观测故障：是否 fail open 取决风险。降级路径也要演练。

## 9. SLO

区分 API availability、run completion、time-to-first-update、任务成功、stuck/approval time、cost、安全。长任务用完成时限分布，不用单 HTTP P99 表示全部体验。

## 10. 容量与限额

模型 rate/token、并发 run × fanout、DB connections、queue lag、SSE connections、vector QPS、artifact bandwidth。global/tenant/provider/tool bulkhead，预算不足早拒绝而非半途烧完。

## 11. Disaster recovery

备份/恢复演练、RPO/RTO、事件/索引重建、跨区模型/数据限制。vector index 可由源文档重建，但 ACL/version lineage 必须在可靠库。恢复后 pending operation 先 reconciliation。

## 12. Runbook

provider outage、429、stuck run、duplicate write、cross-tenant、cost spike、bad prompt rollout、queue backlog、DB saturation、trace leak。每份有 detection、triage、mitigation、owner、rollback、postmortem。

## 本章速记

生产 Agent 是异步分布式系统。可靠性来自持久状态、至少一次+幂等、版本化灰度、限额降级和演练，而不是更强模型。
