# 第 01 章：Python 语法与数据模型

## 本章目标

用 JS/TS 开发者视角掌握 Agent 工程真正需要的 Python 语法，重点理解引用、可变性、容器、相等性、作用域和模块，而不是逐条背语法。

## 1. 缩进、名称与对象

Python 变量是名称绑定，不是带固定类型的盒子：

```python
items = [1, 2]
alias = items
alias.append(3)
assert items == [1, 2, 3]
```

赋值默认不复制。`is` 比对象身份，`==` 比值；除 `x is None` 等身份语义外，不用 `is` 比字符串或数字。布尔上下文中空容器、空字符串、0、None 为假，但业务上要区分“缺失”和“空值”。

## 2. 基本类型

常用：`None`、`bool`、`int`、`float`、`str`、`bytes`。Python `int` 任意精度；浮点仍有二进制误差，金额用 `Decimal` 或最小货币单位整数。字符串是 Unicode；网络/文件边界明确 encode/decode。

```python
name = "Agent"
message = f"hello {name!r}"
raw = message.encode("utf-8")
```

## 3. 容器选择

- `list[T]`：有序、可变，可重复。
- `tuple[...]`：有序、通常表达固定结构或不可变记录。
- `dict[K, V]`：键值映射，保持插入顺序，但不要把顺序当协议除非显式声明。
- `set[T]`：去重/成员测试，无业务显示顺序。

字典 key 必须 hashable。可变 list/dict 不能当 key。Agent state 若需持久化，优先 JSON 可序列化的明确结构，不把任意对象塞进去。

## 4. 解包、切片与推导式

```python
head, *middle, tail = [1, 2, 3, 4]
names = [u["name"] for u in users if u["active"]]
index = {item.id: item for item in items}
```

推导式适合一眼可懂的映射/过滤；带副作用、嵌套过深或多分支时写普通循环。切片通常生成浅副本，不会深复制元素。

## 5. 控制流与 pattern matching

`if/elif/else`、`for`、`while`、`break/continue` 与 JS 类似，但 `for` 遍历 iterable。循环可带 `else`，仅在未 break 时运行，团队不熟悉时可避免。

```python
match event:
    case {"type": "tool_result", "ok": True, "data": data}:
        handle(data)
    case {"type": kind}:
        raise ValueError(f"unsupported: {kind}")
```

match 是结构匹配，不是 TS 的静态判别联合穷尽检查。外部 dict 仍应先用 Pydantic 验证。

## 6. 真值、短路与默认值陷阱

`value or default` 会把 0、空字符串、空列表也替换。仅在 `None` 表示缺失时写显式判断：

```python
limit = supplied if supplied is not None else 20
```

`and/or` 返回操作数而不一定是 bool。公共逻辑尽量返回明确布尔。

## 7. 浅拷贝与深拷贝

`list(x)`、`x[:]`、`dict(x)` 是浅拷贝；内部可变对象共享。`copy.deepcopy` 不是状态设计的默认答案，可能复制昂贵资源或破坏对象协议。Agent state 优先不可变值、显式 update 和版本化序列化。

## 8. 异常基础

```python
try:
    value = parse(raw)
except ValidationError as exc:
    raise ProtocolError("bad tool output") from exc
else:
    persist(value)
finally:
    cleanup()
```

只捕获能处理的异常，避免 `except Exception: pass`。用 `raise ... from exc` 保留 cause。预期业务失败可用明确结果类型；程序错误不要伪装成普通结果。

## 9. 模块与 import

一个 `.py` 是模块，带 `__init__.py` 的目录通常是 package。优先绝对 import，禁止通配符 import。模块顶层代码在首次 import 时执行，因此不要在 import 阶段连接数据库、读取远程配置或启动 Agent。

```python
def main() -> None:
    ...

if __name__ == "__main__":
    main()
```

## 10. JS/TS 开发者高频误区

- Python 没有 JS `undefined`；通常用 None，但“字段缺失”需 sentinel。
- dict 属性不能默认点访问；Pydantic model/dataclass 才是明确对象。
- 默认参数在函数定义时求值，不能写 `items=[]`。
- `sort()` 原地改并返回 None；`sorted()` 返回新列表。
- `dict.get(k)` 无法区分缺失与值为 None，必要时用 `if k in d` 或 sentinel。
- Python 私有性主要靠约定，`_name` 不是安全边界。

## 本章速记

Python 的核心不是语法短，而是对象、引用和协议。Agent 状态要避免共享可变对象、模糊缺失值和 import 副作用，外部 dict 不能因为 pattern match 成功就变可信。
