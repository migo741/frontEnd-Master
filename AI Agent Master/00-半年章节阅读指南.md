# 半年章节阅读指南｜AI Agent Master

> 本课预算：42 小时。目标是获得 Python/Agent 生产基线并安全接入统一项目，不在半年内追逐所有框架或多 Agent 花样。

等级规则：`A` 是生产 Agent 必学；`B` 优先建立视野或二选一实践；`C` 本轮快读或并入统一项目。

## 框架选择纪律

```text
官方模型 API + 手写 loop（必须）
          ↓
LangGraph 或 OpenAI Agents SDK 选一个深做
          ↓
另一个只完成迁移比较
          ↓
MCP / 多 Agent 按真实集成需求再扩大
```

## 生产 Agent 的最低证据

- 外部数据和模型输出都有运行时 Schema；
- 工具写操作经过代码授权、幂等、审批与审计；
- 长任务可 checkpoint、恢复、取消，不因重放重复副作用；
- 固定 eval 数据集能阻止模型/Prompt/框架升级退化；
- trace 能分辨模型、检索、工具、状态和产品失败；
- prompt injection 下仍不能越权或泄露秘密。

时间不足时先后置 15、21，并在 12/13 中只选一章深做；08、09、16～20 不能跳过。
