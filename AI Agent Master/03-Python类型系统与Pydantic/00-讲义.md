# 第 03 章：Python 类型系统与 Pydantic

## 本章目标

用静态类型让 Agent 代码可维护，用 Pydantic v2 验证运行时边界；清楚二者不互相替代。

## 1. Python type hint 不执行验证

```python
def add(x: int, y: int) -> int:
    return x + y
```

运行时仍可传字符串。Pyright/mypy 在开发期分析；网络 JSON、环境变量、模型输出必须 runtime validate。

## 2. 现代类型语法

```python
def find(id: str) -> User | None: ...
names: list[str] = []
mapping: dict[str, int] = {}
```

使用 `Literal` 表达有限值，`TypedDict` 表达仅供静态检查的 dict shape，`TypeAlias`/3.12+ type statement 命名复杂类型。`Any` 关闭检查，会扩散；未知值用 `object`/`Unknown` 语义并在边界缩小。

## 3. 判别联合与穷尽

dataclass/Pydantic model 配合 Literal 可构造 union。处理后用 `assert_never` 检查静态穷尽。外部数据应先通过 discriminated union Schema，不直接把 dict cast 成 union。

## 4. Protocol 与泛型

```python
class ModelClient(Protocol):
    async def generate(self, request: Request) -> Response: ...
```

结构化 Protocol 适配第三方，无需继承。`TypeVar`/新泛型语法用于输入输出关联；不要把所有函数泛型化。协变/逆变影响 callback、只读 producer 和 consumer，公共库需要理解，业务层保持简单。

## 5. dataclass、TypedDict、BaseModel 怎么选

- frozen dataclass：内部领域值、轻量不可变对象。
- TypedDict：已有 dict 协议的静态 shape，不做 runtime validation。
- Pydantic BaseModel：外部 JSON/config/tool args/model structured output。

不要从数据库到 UI 全程只传一个巨型 BaseModel；边界 model 与领域 model 可分离。

## 6. Pydantic v2 核心

```python
class SearchArgs(BaseModel):
    model_config = ConfigDict(extra="forbid", strict=True)
    query: str = Field(min_length=1, max_length=500)
    top_k: int = Field(default=5, ge=1, le=20)
```

关注：strict/coercion、extra、field/model validator、discriminated union、TypeAdapter、model_dump、JSON Schema。工具参数通常 `extra='forbid'`，避免模型偷偷带未知字段。

## 7. 校验与业务规则

Schema 负责形状和局部约束；“用户是否有权退款”“订单当前能否取消”属于业务服务，不应塞进 Pydantic validator。validator 避免 I/O，保持确定性。

## 8. 序列化不是无损魔法

datetime、Decimal、UUID、enum 在 JSON 中需要明确编码。checkpoint 长期存储必须 version 字段和 migration，不能假定新 class 能读取所有旧 snapshot。

## 9. Tool Schema

Pydantic 可生成 JSON Schema，但供应商支持的 JSON Schema 子集可能不同。生成后做 contract test；field description 要写业务含义、单位和边界，不能把授权信息暴露给模型参数自由选择。

## 10. 配置

环境变量是字符串且可能缺失。应用启动时一次性 parse 为 Settings，失败 fast。secret 用 SecretStr/secret manager，并确保 repr/log/trace 脱敏。

## 11. 严格检查策略

新代码开启 strict；第三方无类型包用窄 adapter/shim 隔离，不把 Any 传遍系统。`cast` 只告诉 checker，不做 runtime 检查；每个 cast 旁应有证明或 boundary test。

## 本章速记

typing 管开发期关系，Pydantic 管运行时数据。Agent 的模型输出和工具参数跨越不可信边界，必须先 Schema，再进入领域逻辑。
