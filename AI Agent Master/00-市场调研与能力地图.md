# 2026 国内 AI Agent 岗位调研与能力地图

> 调研日期：2026-08-04。样本来自企业招聘页、校园就业平台和招聘平台公开职位。它是方向性抽样，不是全国职位总量普查。

## 一、语言结论：Python 是最稳妥主线

近期样本中，Python 是最频繁且跨岗位层级最稳定的语言：

- 华为云 AI Agent 岗位明确要求 Python 和常见 Agent 框架：[岗位样本](https://www.nowcoder.com/jobs/detail/419739)。
- 百度智能体岗位要求 Agent 全链路、ReAct/CoT/Plan-and-Execute，以及 PyTorch、LangChain、AutoGen：[百度校园招聘](https://talent.baidu.com/jobs/detail/GRADUATE/cad8f67a-4118-4e26-a39d-0cc84f699f9d)。
- 小红书大模型应用岗位要求 Python/C++，并将 RAG、多模态、模型工程放在同一能力面：[小红书校园招聘](https://job.xiaohongshu.com/campus/position/17018?referer_code=EJOZXFQLXGQA)。
- 彩讯 AI Agent 应用岗强调 Python 基础，并接受 TypeScript、LangChain、LlamaIndex、Transformers 等能力组合：[职位页](https://career.nankai.edu.cn/correcruit/content/id/110998.html)。
- 拼多多 Agent 研发岗接受 Python/Java/Go/C++，但框架要求仍集中在 LangChain、LlamaIndex、AutoGen、Dify，并要求 MCP、Function Calling 和多智能体实战：[职位页](https://career.nankai.edu.cn/correcruit/content/id/116275.html)。

也存在 Java、Go、TypeScript 专向岗位，例如企业 Java Agent 后端、Go 安全/运行时，以及 TS+Go Agent 产品团队。这说明高级工程师最终要能跨语言设计协议，但不改变 Python 作为学习主线的性价比。

## 二、岗位真正考察的能力

### 1. Agent 核心原理

岗位高频词包括 ReAct、任务规划、多步推理、工具调用、记忆、工作流、多 Agent 和 MCP。只会框架 quickstart 不足以解释 loop、状态、终止、失败恢复和工具副作用。

### 2. RAG 与数据工程

文档解析、切片、Embedding、混合检索、Rerank、引用、权限过滤、知识更新和评测是常见工作。高级要求是用指标证明检索和回答质量，而不是“接了向量库”。

### 3. Python 后端与工程化

FastAPI/异步、数据库、缓存、消息队列、Docker/Kubernetes、CI/CD、日志监控、限流重试、成本优化都很常见。Agent 岗不是 Prompt 岗，而是带概率组件的软件工程岗。

### 4. 模型与推理基础

需要理解 token/context、sampling、structured output、tool calling、embedding、rerank；算法向岗位还会要求 PyTorch、微调、推理部署、vLLM/TensorRT-LLM。应用开发不必从预训练起步，但必须能与算法/平台团队对话。

### 5. 评测与安全

百度近期岗位已经把效果、效率、资源成本纳入一体化量化指标。生产 Agent 还需处理 prompt injection、越权、PII、审批、沙箱、审计和红队测试。

### 6. 产品与业务闭环

职位普遍强调从技术验证到业务落地、指标迭代和跨团队协作。能说明“不用 Agent”的边界、失败时如何降级，比堆框架名更重要。

## 三、语言分工建议

| 语言 | 适合位置 | 本课程定位 |
|---|---|---|
| Python | Agent 编排、RAG、模型生态、数据处理、FastAPI | 主线，完整学习 |
| TypeScript | Web/Node、流式 UI、全栈 Agent、MCP 工具 | 复用你的优势，重点做适配 |
| Java | 企业存量系统、Spring AI、治理与中台 | 学架构映射，不重学 Java |
| Go | 高并发网关、运行时、基础设施与安全 | 理解何时拆出服务 |
| C++/CUDA | 模型推理和性能基础设施 | 应用开发了解接口即可 |

## 四、框架现状

- LangGraph 将自己定位为长期、有状态 Agent 的低层编排 runtime，核心是 durable execution、streaming、HITL、persistence：[官方概览](https://docs.langchain.com/oss/python/langgraph/overview)。
- OpenAI 官方 Agents SDK 同时提供 Python 和 TypeScript，覆盖 tools、handoffs、guardrails、tracing 和 sandbox execution：[官方 SDK 页面](https://developers.openai.com/api/docs/libraries#use-the-agents-sdk)。
- Google ADK 已覆盖 Python、TypeScript、Go、Java、Kotlin：[官方文档](https://adk-labs.github.io/adk-docs/)。
- MCP 官方 Tier 1 SDK 包含 TypeScript、Python、Go，且其他语言生态持续扩展：[官方 SDK 列表](https://modelcontextprotocol.io/docs/sdk)。

因此课程不押注“唯一赢家”。先掌握原理，再用两个代表性 Python 框架，最后通过 provider/tool protocol 隔离变化。

## 六、哪些内容不作为主线

- 从零训练基础大模型；那是另一条算法/基础设施路线。
- 只背 CoT 模板或“神奇提示词”。
- 同时横向浅学十个 Agent 框架。
- 把多 Agent 当成单 Agent 的自动高级版。
- 用模型评模型后就宣称客观正确。
- 把 Dify/n8n 等低代码平台操作当作工程核心；会集成即可。
