# 第 21 章：浏览器、代码、研究与多模态 Agent

## 本章目标

理解四类高级 Agent 的环境、反馈和安全差异，能把通用 runtime 迁移到真实操作型任务，而不是只做文本问答。

## 1. Browser Agent

浏览器状态不只 DOM：登录、iframe、popup、下载、网络、视觉 canvas、动态 UI。优先语义 locator/可访问性树，必要时视觉。每步 observation 要限制大小并保存 screenshot/DOM artifact。

点击/输入前验证域名、目标元素、当前页面和风险；购买、提交、发送、删除需预览/批准。网页内容是不可信输入，不能让页面指令改变系统目标。

## 2. Code Agent

环境包括 repo snapshot、任务、测试、工具、sandbox、版本控制。先理解/计划，做小 patch，运行 formatter/typecheck/test/security，展示 diff。禁止无授权读取 home/secret、推送、部署或删除。

测试通过不代表需求正确；用 hidden tests、review、static analysis、dependency policy 和任务 eval。生成代码执行必须沙箱。

## 3. Research Agent

把问题拆子问题，制定搜索策略，保存 source snapshot、时间、可信度与 claim-evidence graph；去重、处理冲突和新鲜度。最终每个可验证 claim 有引用，未知明确标记。

网页可能恶意，私有 CRM 与公共 Web 组合有数据外泄风险；research worker 通常只读且不同时持高敏数据/外发能力。

## 4. Multimodal

图像、音频、视频、PDF 有 token/带宽/隐私成本。预处理（OCR、抽帧、VAD、缩放）要保留原始 artifact/时间位置；模型结果带 bounding box/page/timestamp 证据。不要把 OCR 文本视为可信指令。

## 5. Computer use 的不稳定性

像素/GUI 操作对布局、延迟、弹窗敏感。能用 API/结构化 tool 就不用鼠标；computer use 是最后一公里。设置步数、域名、动作 allowlist、截图审计和人工接管。

## 6. Artifact-first

长研究、代码、表格、媒体结果以 artifact 存储，Agent state 只保留 id/metadata/摘要。artifact 有 provenance、checksum、ACL、version、retention，防 context 爆炸和结果丢失。

## 7. 环境反馈

Agent 成功必须由环境验证：页面出现确认号、测试退出码、编译器输出、来源支持、图像坐标一致。模型自述“已完成”不作为终态。

## 8. 技能/工具选择

按任务动态加载最小工具/skill；复杂工具说明按需 retrieval。工具目录本身需版本/权限。技能文本也可能被污染或过时，像代码一样 review/test。

## 9. 评测

- Browser：任务成功、无误动作、步骤、恢复、站点变化。
- Code：tests、patch correctness、regression、安全、diff size。
- Research：claim coverage、citation correctness、source quality、新鲜度。
- Multimodal：字段/定位、漏检/误检、隐私、人工复核。

## 10. 何时专用模型/框架

按环境操作能力和 eval 选，不因 demo 排行直接替换。通用 control plane（run/budget/tool/security/trace）保持统一，environment adapter 专用。

## 本章速记

高级 Agent 的核心是环境反馈和受控动作。浏览器、代码、研究、多模态需要不同 observation/action/validator，但共享预算、权限、沙箱、artifact 和 eval。
