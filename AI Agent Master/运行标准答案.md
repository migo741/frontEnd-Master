# 运行标准答案

每章的 `02-答案/reference/` 都包含实际源码和自动化测试，不需要 API Key 的离线实现必须先通过；涉及真实模型、LangGraph、Agents SDK、MCP 或 FastAPI 的章节还提供相应集成文件。

## 推荐环境

```bash
cd "AI Agent Master"
uv sync --all-extras
uv run python run_all.py
```

没有 `uv` 时：

```bash
python3.13 -m venv .venv
source .venv/bin/activate
python -m pip install -e '.[frameworks,test]'
python run_all.py
```

只运行一章：

```bash
python "09-工具工程与外部系统集成/02-答案/reference/test_solution.py"
```

## 代码分层

- `solution.py`：完全离线、确定性、可测试的核心参考实现。
- `test_solution.py`：本章练习要求对应的正常、异常和安全测试。
- `*_integration.py`：需要第三方框架或真实服务的集成示例；默认不发起收费请求。
- 其他文件：示例数据、Docker、配置或架构骨架。

## API Key

标准测试不需要任何模型 API Key。只有你主动运行 live 示例时才从环境变量读取 Key；源码、测试数据和默认日志均不保存 Key。

## 说明

代码答案刻意控制为“能够完整说明本章核心机制的最小生产化实现”，不是复制粘贴即可承载真实资金或客户数据的成品。上线前仍需替换内存存储、接入真实认证/密钥系统、完成容量与安全评审。
