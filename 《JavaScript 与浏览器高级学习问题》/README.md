# JavaScript 与浏览器高级学习指南

这不是一本“背 API 的 JavaScript 语法书”，而是一条从 **JavaScript 中级 + Vue 3 中级 + React CRUD 初级**，走向高级前端候选人的证据化训练路线。

课程重点回答三类问题：

1. 一段 JavaScript **为什么**这样运行，而不只是输出是什么；
2. 浏览器从事件、网络、存储到像素，在哪些边界会出现竞态、卡顿、泄漏与安全事故；
3. 这些底层机制如何决定 React 中闭包、状态快照、Effect、并发 UI、性能和架构的正确写法。

> 学完文档不等于自动获得“大厂高级职级”。完成全部练习、毕业项目和证据材料后，你会拥有接近高级岗位要求的知识结构与作品证据；真实职级还取决于生产规模、业务结果和跨团队影响力。

## 固定学习结构

```text

├── 00-讲义.md
├── 01-练习/
│   └── README.md
└── 02-答案/
    └── README.md
```

- `00-讲义.md`：先建立心智模型，预测反例，理解生产边界。
- `01-练习/README.md`：恰好两道题；第一道是经典必做，第二道是高难生产题。
- `02-答案/README.md`：给推导、参考实现、测试与权衡。卡住 60–90 分钟后可以看，但看完必须关掉答案复写。

## 课程地图

### 第一阶段：语言内核（01–08）

值与边界 → 闭包与 `this` → 对象模型 → 不可变状态 → 异步语义 → 迭代与流 → ESM → 前端算法。

目标：能从 ECMAScript 语义解释问题，写出有边界、有取消、有复杂度意识的基础模块。

### 第二阶段：浏览器平台（09–15）

DOM 与事件 → 渲染与帧 → Fetch 与实时通信 → 存储与离线 → Worker 并行 → Web 安全 → 引擎、内存与性能。

目标：能用 DevTools 和运行时证据定位体验、稳定性和安全问题，而不是靠“加 memo”“换库”碰运气。

### 第三阶段：生产工程与 React 桥接（16–18）

测试调试与可观测 → JS 到 React 心智模型 → React 毕业项目与系统设计答辩。

目标：把机制变成可交付、可回归、可说明取舍的工程能力。

## 两种学习路线

### 标准路线：24–32 周

- 每周学习 4–5 天，每次 2–3 小时。
- 每章 5–9 小时；高难题允许跨两天。
- 第 01–17 章约 140–220 小时，毕业项目约 80–140 小时。
- 每完成一个阶段，暂停一周做错题复写和证据整理。

### 冲刺路线：14–18 周

- 已掌握的讲义仍要完成自检，但每章只做练习一。
- 练习二先写设计、风险和测试，再对照答案复写关键部分。
- 第 05、09、10、11、14、15、17、18 章不得跳过。

## 每章通过标准

以下五项全部满足才算完成：

- 不看文档，能用自己的话讲清本章核心因果链；
- 独立完成练习一，测试覆盖关键边界；
- 对练习二至少提交设计草图和失败记录；
- 对照答案后，从空文件复写关键实现；
- 保留一种证据：测试、时间线、Performance 记录、Heap Snapshot、网络瀑布图或安全威胁模型。

## 最终能力证据

完成课程后，你应能展示而不是只声称：

- 一套正确处理取消、乱序、重试、背压与错误归属的异步模块；
- 一个能解释 live binding、循环依赖、代码分割和模块副作用的工程案例；
- DOM 事件、渲染流水线、跨标签页一致性和 Worker 的实际实现；
- XSS、CSRF、CSP、Trusted Types、`postMessage` 的分层防护；
- 带性能基线、Core Web Vitals、内存快照和回归测试的优化报告；
- 一个 React 19.2 主线、可兼容企业 React 18 心智模型的毕业项目；
- 架构决策记录、故障复盘和 45 分钟技术答辩材料。
