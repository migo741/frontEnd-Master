# 半年章节阅读指南｜JavaScript 与浏览器

> 本课预算：70 小时。总路线见上一级 `00-半年总学习路线.md`。本指南是在九套 Master 同时学习的约束下制定，不替代原课程的标准深学路线。

## 本课定位

这是 Vue、React、Node 和前端架构共同依赖的运行时地基。你已有 JavaScript 中级水平，因此不按语法顺序平均用力：异步、模块、浏览器渲染、网络、安全、性能和可靠交付必须深做；与独立 DSA、React Master 重复的内容只建立映射。

等级规则：`A` 高级开发必学并留证据；`B` 优先学习并完成核心题；`C` 本轮快读，深做交给对应 Master。

## 本课必须留下的四项证据

1. 一个有取消、并发上限和确定性测试的异步模块；
2. 一份浏览器 Performance trace 与优化前后数据；
3. 一份 XSS / postMessage 信任边界威胁模型；
4. 一份偶发故障时间线、根因、回滚与回归测试。

如果 70 小时用完仍有欠账，先放弃 03、06、12、13 的高难题，不削减 05、11、14、15、16。
