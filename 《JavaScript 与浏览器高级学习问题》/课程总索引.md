## 强制阶段关卡

### 关卡 A：语言内核

独立实现一个有测试的模块，必须同时展示：值边界、不可变状态、异步取消、错误归属、复杂度说明和 ESM 边界。

### 关卡 B：浏览器平台

用原生 Web API 完成一个小型页面，必须同时展示：可访问事件交互、帧预算、流式网络、离线/跨标签页、Worker、安全策略、性能与内存证据。

### 关卡 C：高级 React 候选人

完成第 18 章项目，并能把每个 React 决策追溯到 JavaScript 或浏览器机制；45 分钟内完成架构答辩，现场增加一个带竞态或性能约束的需求。
