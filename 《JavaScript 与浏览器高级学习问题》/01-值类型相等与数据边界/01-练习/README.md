# 第 01 章练习

规则：先独立完成测试矩阵，再实现代码。两题之外不加题量。

## 练习 1（经典必做）：实现 SameValue

不调用 `Object.is`，实现：

```js
function sameValue(a, b) {}
```

要求：

1. 行为必须与 `Object.is` 一致。
2. 至少覆盖普通值、对象身份、`NaN`、`0`、`-0`。
3. 写出它与 `===`、SameValueZero 的差异表。
4. 回答：若状态容器用它判断新旧状态，重复写入 `NaN` 和从 `0` 写入 `-0` 会怎样？

禁止只贴著名的一行答案；先写因果说明和失败用例。

验收命令可自行选择 Node 测试框架，也可直接使用 `node:assert/strict`。

## 练习 2（高难）：设计无歧义 JSON 数据边界

实现 `encode(value)` 与 `decode(text)`，用 JSON 文本传输以下值：

- `undefined`、`NaN`、`Infinity`、`-Infinity`、`-0`；
- BigInt、Date、Map、Set；
- 普通对象与数组的任意嵌套组合。

约束：

1. 普通用户对象可能含有 `$type`、`value` 等字段，编码不能与业务数据冲突。
2. 遇到循环引用必须报错，并指出第一次发现循环的路径。
3. 解码只恢复白名单类型，不能按输入指定任意构造器。
4. Map 的键可以是上述可编码值；对象属性中的 `undefined` 必须保留。
5. 提供至少 12 个往返测试，并明确“身份共享”是否在协议范围内。

交付：契约说明、完整实现、测试、一个你明确拒绝支持的值及理由。
