# 第 18 章练习

## 练习一：完成并答辩“高性能协作工单运营台”

按讲义 M0–M7 实现项目。不是所有功能都要做得庞大，但每个关键机制必须有一个可验证的垂直切片。

最低交付：

- 可运行项目与唯一 lockfile；
- URL 筛选 + 万级虚拟列表 + 可访问键盘交互；
- 详情编辑、自动保存、乱序防护、版本冲突；
- IndexedDB outbox、离线恢复、多标签页通知；
- Worker 计算与有界消息协议；
- 富文本安全、权限/CSRF 方案、威胁模型；
- 单元/集成/关键 E2E、性能与内存报告；
- release/错误/Web Vitals 观测与灰度回滚说明；
- 至少 6 份 ADR、一次事故复盘、15 页以内答辩材料；
- AI-native 流式扩展或一份完整的设计/评估方案。

演示必须现场切换到慢网、离线，并注入一个旧响应晚到。若只能在理想 happy path 运行，不算完成。

## 练习二：90 分钟生产变更与故障演练（高难）

在项目完成后随机抽取一个变更：

1. 批量操作改为最多并发 3 个，支持取消且保持结果顺序；
2. 另一个标签页更新当前工单时，编辑器不得静默覆盖；
3. 实时推送从每秒 5 条增到 500 条，输入仍需响应；
4. 富文本新增外链与图片，安全和性能预算不退化；
5. AI 建议动作新增 tool call，高风险动作必须人工确认且可审计。

时间盒：

- 0–15 分钟：澄清约束、写状态机/威胁/性能假设；
- 15–60 分钟：实现最小垂直切片与测试；
- 60–75 分钟：故障注入和 profile；
- 75–90 分钟：写 ADR、剩余风险、发布/回滚计划并口头答辩。

评分重点不是完成 UI 数量，而是能否保护原有不变量、用证据控制风险，并清楚说明暂未完成什么。
