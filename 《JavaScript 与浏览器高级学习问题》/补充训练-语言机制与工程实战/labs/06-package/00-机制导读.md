# 06 · 机制导读

一个函数在本文件里能跑，并不等于另一个项目能正确消费它。包的公开入口、文件清单、模块格式、导入副作用和环境假设也是交付的一部分。

本单元做小型TTL/LRU缓存，重点有两层：缓存行为契约与真实发布产物边界。只做ESM，避免为没有需求的双模块格式增加复杂度。

TTL决定数据是否仍有效，LRU决定容量不够时淘汰谁。这两个规则相互独立：get刷新最近使用顺序，本题不延长过期时间；set覆盖则重置TTL。

时间来自注入的now函数，因此可以精确测到到期边界，无需等待真实时钟。[Node 包入口文档](https://nodejs.org/api/packages.html#package-entry-points) 说明exports和公开路径的关系。
