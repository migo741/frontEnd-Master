# 06 · 实现并交付TTL/LRU模块

编辑src/index.js；src/package.json已经给出可运行的ESM包边界，你需要理解并在迁移时维护它。

```js
const cache=createCache({capacity=2,ttl=1000,now=Date.now});
cache.set(key,value);
cache.get(key); // {hit:true,value} 或 {hit:false}
cache.delete(key); // boolean
cache.size; // 当前未过期条目数
```

契约：

- capacity为正整数；ttl为有限正数；now为函数，练习时返回单调不减的毫秒数。
- 支持Map可接受的任意key，对象键按身份区分；允许缓存undefined，不能把它当miss。
- set按写入时刻重置TTL，并成为最近使用项；get命中刷新LRU但不延长TTL。
- `now() >= expires`即过期。过期条目不占有效size；set前清理过期项，再按LRU淘汰到容量内。
- 多个cache实例相互隔离。没有后台timer；没有导入即创建全局单例或修改globalThis。
- 公共入口只有包根。实现文件可以进入tarball，但未导出的子路径不能经包名直接导入。

运行 `node scripts/test.mjs 06`。最后一项实际npm pack到临时目录，解开tarball到一个独立consumer的node_modules后按包名导入；检查行为、globalThis变化和子路径封装。测试不会发布包，也不需网络依赖安装。

验收：5项公开测试通过；另加“过期最旧项与有效LRU竞争时正确淘汰”的用例。手动执行一次 `npm pack --dry-run` 查看文件清单，解释exports、files、sideEffects各负责什么。sideEffects是给工具的声明，本身不阻止代码产生副作用。
