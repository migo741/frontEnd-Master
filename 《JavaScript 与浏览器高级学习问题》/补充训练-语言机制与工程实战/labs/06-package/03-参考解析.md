# 06 · 参考解析

Map保存key→{value,expires}，最前面是最久未使用项。get先检查过期，再把有效项移动到最后；set先prune过期项、删除旧项、写入新的expires，最后从头淘汰超额项。

参考实现为便于验证，prune扫描全部条目，因此set和size为O(capacity)，get/delete期望O(1)。有界小缓存可以接受这项取舍；不能把“用了Map”直接写成所有操作O(1)。

package.json的exports只开放根入口；files决定tarball包含的文件；type指定.js按ESM解释。reference标记sideEffects:false，与源码确实没有导入时外部动作相对应，不将它当作安全机制。

测试先npm pack真实生成tarball，再在临时consumer安装其内容。这样若忘记包含index.js或错误配置入口，会在真实模块解析阶段失败。结束后删除测试自己创建的临时目录，不改原课程或系统配置。
