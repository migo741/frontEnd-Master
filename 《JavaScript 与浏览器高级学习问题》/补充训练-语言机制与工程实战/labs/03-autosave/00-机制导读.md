# 03 · 机制导读

原课第04章 reducer 只负责“状态如何变化”。它返回 SAVE command 时，网络还没有发生。command runner 才拥有请求、AbortController、错误观察和请求完成后的事件回写。

本单元提供与原练习接口相同的 state.js。你应复用它，避免把网络塞回 reducer。

区分三种身份：

- editVersion：本地编辑快照的序号。
- requestId：某一次保存尝试的身份。
- epoch：打开/结束文档会话的代次，即使重新打开同一个 docId 也要改变。

serverVersion 又是另一层事实：它来自服务端并用于冲突检测，不能拿 editVersion 替代。

取消与正确性要分开：abort 请求可能被 transport 忽略；旧结果必须在提交状态前检查自己仍属于当前会话。浏览器中的 mock transport 允许主动忽略取消，以稳定验证这一点。
