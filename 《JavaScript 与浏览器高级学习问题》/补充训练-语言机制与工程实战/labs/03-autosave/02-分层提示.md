# 03 · 分层提示

1. 每个异步保存循环创建 owner，保存 epoch 和 AbortController。结果提交前比较 owner.epoch 与当前 epoch。
2. reducer 返回 commands 后 runner 才执行 transport。不要在 EDITED 内把文本发到网络。
3. transport 可同步抛错，也可返回 thenable，因此调用和 await 应在同一个 try 中。
4. save 不能简单声明成 async 后直接 return flight.promise：async 函数会包出不同 Promise 身份。若契约要求对象相同，外层使用普通函数。
5. 旧请求的 finally 不能无条件把新会话 flight 清空。仅当当前 flight 仍是自己的 owner 时释放。

服务端版本与本地编辑版本分开更新；保存完A后，savedVersion确认A，text仍可为B。
