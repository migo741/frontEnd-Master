# 03 · 接通自动保存完整链路

编辑 src/index.js，实现 `createEditor({docId,text='',serverVersion=0,transport})`。

## API

- getSnapshot() 返回 `{docId,serverVersion,text,editVersion,savedVersion,request,error,disposed}`。视为只读数据；本题不要求深冻结 Error 或其他嵌套对象。
- edit(text)：只接受字符串，同值不增加版本。
- save()：返回 Promise。同会话已有保存循环时返回**同一个 Promise**；无 dirty 时不发请求。
- open({docId,text='',serverVersion=0})：结束旧会话并打开新会话，重置本地编辑状态。
- dispose()：幂等，取消当前会话，阻止新 edit/save/open；getSnapshot 仍可查看最终状态。

## transport 协议

```js
transport({docId,text,baseVersion,requestId,signal})
// 同步值或 Promise，成功形状：{serverVersion:正整数}
```

成功 serverVersion 必须为整数且严格大于请求前的版本；无效结果作为失败处理。真实接口通常还有 schema 和实体标识，本题先约束这条最小协议。

## 保存语义

1. 同一活动会话最多一个在途请求。save 被调用后，可以延至微任务启动 transport，但必须先安装 flight 身份，避免同栈重复启动。
2. 请求使用不可变文本/编辑版本快照。保存期间继续编辑，旧成功只确认旧版；循环接着保存新版本，直到干净才完成 save Promise。
3. 任何当前请求失败（同步异常、异步拒绝、409或无效版本）都停止循环：清除 request、保留草稿和 dirty、记录原始错误、拒绝 save Promise。用户调用 save 显式重试。
4. open/dispose 后旧结果不得修改当前状态，旧失败仍被观察。原 save Promise 在旧 transport 最终结算后正常结束；它不保证在 abort 时立刻结算。
5. 被取消的 transport 如果从不结算，旧 Promise 可能一直 pending。不得声称 abort 能强行终止任意异步工作；新会话仍可保存。
6. 无自动无限重试；409 不静默覆盖服务端事实。重新打开文档时会舍弃当前会话草稿，本题尚未实现离线/跨文档草稿持久化。

## 实现阶段

A. 只做 edit → SAVE_REQUESTED → transport → 成功/失败事件。
B. 在保存中再编辑，串行排空 dirty；再做同栈 save 去重。
C. 加 open/dispose 代次守卫，复现忽略 abort 的迟到成功和拒绝。
D. 接到现成页面，完成失败重试和409演示。
