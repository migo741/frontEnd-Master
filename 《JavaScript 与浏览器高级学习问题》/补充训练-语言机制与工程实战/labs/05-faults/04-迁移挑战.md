# 05 · 迁移挑战

1. 搜索结果增加缓存：旧请求可以填缓存，但不能显示在当前查询中。为缓存写入与UI提交分别定义资格。
2. 面板增加ResizeObserver或timer，要求同一个dispose负责全部清理；真实浏览器重复安装卸载后留下证据。
3. 表格改为动态行高与可见区渲染，保留滚动锚点。比较仅批量读写和减少DOM数量解决的是哪一类成本。

增加一个“未提前告诉根因”的变体：自己引入一种故障，写复现说明但不给修复提示，隔天用完整排障流程再处理。

4. 发布现场增加未知schema：既保留可关联release的错误日志，又呈现可重试的降级页面。设计下一代SW的缓存迁移与回滚演练，证明旧/新会话均有确定结果。
