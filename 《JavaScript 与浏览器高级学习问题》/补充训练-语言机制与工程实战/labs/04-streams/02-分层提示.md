# 04 · 分层提示

1. 只在batch满时await handleBatch，随后创建新数组；不要复用已经传出的数组。
2. 想清楚迭代器什么时候取得、什么时候自然结束。用done区分自然耗尽与异常提前退出。
3. try/finally保证清理；另外记住是否已有主错误，防止cleanup错误覆盖它。
4. Worker检查cancelled标记之前，必须允许接收cancel消息。一个长同步循环里重复检查Set并不能让message handler运行。
5. 主线程等待批次ACK之后再继续上游，可以建立应用层的需求传递；将所有job提前创建再Promise.all无法达成同样上限。
