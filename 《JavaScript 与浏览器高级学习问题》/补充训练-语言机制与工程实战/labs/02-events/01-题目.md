# 02 · 实现可重入事件模块

编辑 src/index.js，实现：

```js
const hub=createHub({onError(error){}});
const off=hub.on(type,callback,{once:false,signal});
hub.emit(type,payload);
off();
hub.dispose();
```

## 契约

- 同类型订阅按注册顺序调用；相同 callback 注册两次得到两份独立订阅。
- 普通 emit 同步完成分发。回调内重入 emit 只入队，当前事件分发完再按 FIFO 处理。
- 每个事件开始时取订阅快照；过程中新增者不参与本轮；已经移除者本轮也跳过。
- once 在调用前移除。off 幂等；预取消 signal 不安装订阅；abort 后移除订阅和相应 abort listener。
- callback 同步抛错交给 onError，其余订阅继续；onError 自己同步抛错也不能破坏分发。
- dispose 幂等，移除全部订阅和 abort listener，并停止当前事件剩余回调与排队事件。
- dispose 后 emit 静默忽略，on 抛错。callback 必须为函数。

本版只定义**同步 callback**。async callback 返回的 Promise 不由模块等待；不要传入异步回调后假设本版会接管其拒绝。持续无限 emit 的用户回调也可能饿死线程，FIFO 不等于公平调度。
