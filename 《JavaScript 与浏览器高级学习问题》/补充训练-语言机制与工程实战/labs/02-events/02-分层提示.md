# 02 · 分层提示

1. 不要直接把函数当唯一订阅身份。每次注册创建 record，保存 callback、active、once 和 off。
2. record.active 解决“快照里还有，但刚刚被别人删除”的问题。新增订阅不会进入已经取得的数组。
3. 使用 draining 标志；嵌套 emit 只 push。最外层 drain 用循环处理队列。finally 要清理队列和标志。
4. off 是共享释放入口：先标记 inactive，再从 bucket 删除、解除 abort listener。once 和 dispose 复用它。

不要在重入队列中无限 shift 大数组；游标遍历之后统一释放更容易控制大量事件的移动成本。
