# 01 · 12 个机制实验

对应原课 01–03、05–06。只编辑 `src/predictions.json`，不要修改 cases.js 让测试通过。

打开 [cases.js](cases.js)，逐项阅读 run。测试会以 `item.run()` 的方式调用每项；函数体里的普通嵌套函数仍按其自身调用方式决定 this。预测值必须能被 JSON 表达。

| id | 需要回答的机制问题 |
|---|---|
| conversion | + 和 String 分别给什么 hint，valueOf 是否还执行？ |
| tdz | typeof 是否总能安全读取未初始化的名字？ |
| binding | 方法提取、call 和工厂返回的箭头函数如何确定 this？ |
| bound-constructor | new 一个绑定函数是否仍使用 bind 的接收者和参数？ |
| receiver | 继承 Proxy 的对象访问 getter，this 应是谁？ |
| invariant | 冻结目标能被 get trap 报成另一个值吗？ |
| thenable | then getter、then 方法、同步代码、await 续体分别何时执行？ |
| iterator-close | break 时生成器的 finally 是否执行？ |
| sparse | hole 与显式 undefined 在 map、in、JSON、展开中有何差异？ |
| home-object | 把有 super 的方法复制到别处，会改变 super 的起点吗？ |
| function-prototype | typeof 为 function 的值是不是合法对象原型？ |
| then-getter-error | Promise.resolve 读取 then 失败，是同步抛出还是返回拒绝的 Promise？ |

步骤：①每项预测与因果推导先写入自己的证据文件；②填写 JSON；③运行 `node scripts/test.mjs 01`；④保留错误预测并解释偏差。

通过要求：12 项预测经过推导修正；至少自己改写3个变体，例如删掉 Symbol.toPrimitive、Reflect.get 不传 receiver、把 break 改为完整消费。只把测试结果抄进 JSON 不算完成。
