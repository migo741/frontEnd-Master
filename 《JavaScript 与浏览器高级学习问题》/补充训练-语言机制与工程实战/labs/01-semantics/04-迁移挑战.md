# 01 · 迁移挑战

任选一个完成，不提前复制现成实现。

1. 写一个只记录属性读取的 Proxy；用继承 getter、Map.size、class 私有字段、冻结属性验证它能否透明替代原对象。把不能保证的语义明确写进契约。不要用“所有方法自动 bind”掩盖接收者改变。
2. 给序列化器定义 sparse array 政策：明确拒绝 hole，或编码 hole 标签。证明 hole、undefined、null 三者按契约得到处理。
3. 写一个“观测函数调用”的包装器审查报告：列出 this、同步抛错、then getter、Promise 身份与未处理拒绝的相互影响。选择一个有限契约实现，不声称对任意对象完全透明。

交付：新增最小代码、至少4个反例、与原生语义的对照以及明确不支持的边界。
