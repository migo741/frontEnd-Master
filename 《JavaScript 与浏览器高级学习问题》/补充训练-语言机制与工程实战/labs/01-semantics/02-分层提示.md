# 01 · 分层提示

只读当前卡住的一层。

**第一层：先分类。**把观察分成同步属性访问、函数调用、异步 reaction 三种，不要把 getter 当普通字段。

**第二层：画隐式参数。**给每个 getter/函数写出 receiver/this；给每次对象转换写出 hint。给 bound constructor 分别画预置参数和被忽略的绑定接收者。

**第三层：查协议边界。**TDZ 已有词法绑定但尚未初始化；Proxy invariant 是语言必须维护的约束；super 保留方法的 HomeObject；IteratorClose 关的是迭代协议资源。

thenable 题可画四格：读取 then → 当前同步代码结束 → 调用 then 的作业 → await 恢复。遇到 getter 抛错时，先判断“哪个 API 接住了它”。
