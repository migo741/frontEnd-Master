# JavaScript 深度与工程实战 · 补充训练

这套材料承接《JavaScript 与浏览器高级学习问题》，补上机制小实验、章节之间的工程连接、可运行故障现场和模块交付。原有作业继续复用。

## 先运行

在终端进入本 README 所在目录。已用 Node.js **v24.17.0** 验证，需 Node 24+、npm；第 06 单元还使用 macOS 自带 tar。没有外部 npm 依赖，不需要 npm install。

```sh
node --version
node scripts/test.mjs 01
node scripts/server.mjs
```

浏览器打开 [本机训练入口](http://127.0.0.1:4173)。服务仅监听本机，Ctrl+C 关闭。若端口占用，运行 `PORT=4174 node scripts/server.mjs`，用新端口访问。

也可以用 `npm start`、`npm run lab:03` 等同名快捷脚本。npm 可能写自己的日志缓存；测试包打包时使用独立临时缓存，不改系统 npm 配置。

**初始测试失败是预期。** `src/` 是你要填写或修复的代码；01 单元预测为空，02/03/04/06 是待实现接口，05 是能运行的故障实现。

```sh
node scripts/test.mjs 03              # 只测自己的第03单元
node scripts/test.mjs                 # 测全部学生实现
node scripts/test.mjs 03 --reference  # 检验该单元参考实现
node scripts/test.mjs --reference     # 验证完整答案环境
```

参考模式通过只说明参考材料可运行，不能算你完成作业。不要用复制整份答案让测试变绿来替代独立练习。

## 每个单元真正需要提交什么

1. 自己的 `src/` 代码；01 则提交 predictions.json 和解释。
2. 题目规定的测试或运行证据，并自行补至少一个不同于公开测试的反例。
3. 一份简短复盘：第一假设、失败证据、根因、修复为何有效、尚未覆盖的边界。
4. 完成一个迁移挑战；若没做，记录为“专项通过，迁移未验证”。

把 [证据模板](templates/证据记录.md) 复制到自行创建的 `work/单元号/`。Performance trace、Heap Snapshot 和操作录屏都保存在那里，避免与题目和答案混放。

## 通过标准

| 状态 | 证据 |
|---|---|
| 能解释 | 不看答案，能说清因果链和反例 |
| 能实现 | 学生模式测试通过，能说明每项契约 |
| 能排错 | 主动复现失败，用证据排除至少一个错误假设 |
| 能迁移 | 改一个约束后仍保持原有行为，并补回归测试 |

公开测试是可见的回归下限。它没有穷尽输入、浏览器兼容、所有时序，也不能独自认定高级职级。浏览器内存与性能必须另留真实证据，不能以 Node 中的资源计数或模拟布局测试冒充 Heap/Performance 结论。

## 目录

```text
labs/        每单元的讲义、题目、提示、答案、src 与 reference
tests/       52 项公开测试，按 LAB_MODE 选择实现
web/         学生/参考模式共用的页面、传输适配器与 Worker 入口
scripts/     测试启动器、只监听本机的静态/流服务
templates/   证据与进度模板
```

浏览器页面默认加载 src，网址加 `?mode=reference` 才加载答案。03/04 学生接口未实现时会显示 TODO 提示；05 学生页面可直接复现故障。

本版没有完整后端、登录权限、离线数据库、生产 RUM 或多租户发布系统；这些属于原课程的后续综合项目。这里用可控 transport 和固定数据，把每个训练目标做成可检验的小工程。

阅读 [原课衔接与勘误](原课衔接与勘误.md) 查看具体补充位置；阅读 [验收记录](验收记录.md) 查看作者已经实际验证了什么。
