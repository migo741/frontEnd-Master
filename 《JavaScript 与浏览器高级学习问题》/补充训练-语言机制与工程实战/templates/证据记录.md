# 单元 __ · 我的证据

- 日期 / Node / 浏览器版本 / 系统：
- 学生实现 commit 或文件版本：
- 完成状态：能解释 ☐ 能实现 ☐ 能排错 ☐ 能迁移 ☐

## 1. 契约与预测
输入、输出、失败归属、取消策略、资源所有者；哪些顺序有保证，哪些没有？

## 2. 失败现场
最小复现步骤、预期、实际；附失败测试、日志或浏览器记录。

## 3. 竞争假设
至少两个可能原因；每个原因分别被什么证据支持或排除？

## 4. 修复与回归
最小改动是什么？原失败为什么现在不再发生？新增反例是什么？

## 5. 运行证据
命令与结果；浏览器操作顺序；trace / heap 文件名。
性能：记录设备、数据规模、热身与重复次数，至少5次同条件样本和中位数。
内存：相同操作前后快照、可疑对象的 retaining path，区分存活增长与暂时分配。

## 6. 迁移挑战与限制
新增约束、改变的契约、原有回归是否通过；暂未覆盖什么？
