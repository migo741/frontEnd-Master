# 半年章节阅读指南｜TS Master

> 本课预算：55 小时。目标不是类型体操，而是让非法状态难表达、外部数据先解析、公共 API 好推断、大型代码库可演进。

等级规则：`A` 高级开发必学并深做；`B` 优先学习，完成一题并读懂另一题；`C` 本轮建立地图或并入统一项目。

## 逐章路线

| 章 | 等级 | 小时 | 本轮学习动作 |
|---:|:---:|---:|---|
| [01 类型系统心智模型](./01-类型系统心智模型/00-讲义.md) | A | 3 | 两题至少做第一版；能明确区分注解、断言、运行时验证和结构类型的权限风险。 |
| [02 严格模式与字面量推断](./02-严格模式与字面量推断/00-讲义.md) | A | 4 | 配置注册表必做；为统一项目开启 strict、noUncheckedIndexedAccess、exactOptionalPropertyTypes，并记录迁移例外。 |
| [03 控制流分析与类型缩小](./03-控制流分析与类型缩小/00-讲义.md) | A | 3.5 | WebSocket 事件路由必做；Reducer 题至少完成判别联合、never 穷尽和负向类型测试。 |
| [04 对象建模与精确可选](./04-对象建模与精确可选/00-讲义.md) | A | 3 | 用户更新协议必做；能解释缺失、undefined、null、清空和 Patch 三态，停止滥用 Partial。 |
| [05 函数重载与型变](./05-函数重载与型变/00-讲义.md) | A | 2.5 | EventEmitter 必做；高难题只需做重载/联合/泛型决策和型变反例。 |

| [11 类、装饰器与元编程](./11-类装饰器与元编程/00-讲义.md) | C | 1 | 读完类的双重身份、override、标准/旧装饰器边界；不在本轮深做 DI 或元数据框架。 |
| [12 异步、并发与取消建模](./12-异步并发与取消建模/00-讲义.md) | A | 4.5 | 限流任务池必做；NDJSON AsyncIterable 至少完成取消、关闭传播和背压测试。 |
| [13 tsconfig、模块与 ESM/CJS](./13-tsconfig模块与ESM-CJS/00-讲义.md) | A | 3.5 | “编辑器正常、运行失败”必做；为 browser、Node、test 拆配置并理解 paths 不改运行时解析。 |
| [14 声明文件与类型库发布](./14-声明文件与类型库发布/00-讲义.md) | B | 2 | 发布 codec 题做最小包；遗留插件题读答案，知道 exports、declaration、SemVer 和类型消费测试。 |

## 必须形成的能力链

```text
01/02 类型边界
  → 03/04/05 控制流与 API
  → 06/09 领域模型
  → 10 运行时解析
  → 12 异步协议
  → 13/15/16 跨运行时与大型工程
```

## 本课必须留下的证据

- 一个从 `unknown` 解析到领域模型的版本化 Schema SDK；
- 一组正向运行时测试与负向类型测试；
- 一个不使用 `any` 泄漏的领域状态机；
- 一份 tsconfig/ESM 边界说明和大型仓库诊断记录。

时间不足时先放弃 08 高难题、11 实现和 14 遗留插件题；09、10、12、13、15 不降级。
