# 2026 国内 TypeScript 岗位调研与能力地图

> 调研时间：2026-08-03。TypeScript 很少作为独立岗位出现，它通常与 React/Vue、Node、工程化、跨端和 AI 产品共同考察。以下是代表性样本归纳，不代表每家公司都使用同一栈。

## 二、官方版本变化

- 官方 GitHub Releases 在调研日标记最新稳定为 **TypeScript 6.0.3**：[Releases](https://github.com/microsoft/TypeScript/releases)。
- TypeScript 6.0 于 2026-03 发布，是现有 JS 代码线最后一个大版本，集中加入/推进面向 TypeScript 7 的 breaking changes 和 deprecations：[Announcing TypeScript 6.0](https://devblogs.microsoft.com/typescript/announcing-typescript-6-0/)。
- 官方说明 TS 6 是 5.9→7.0 的桥接，TS 7 原生 Go 实现提供显著性能潜力，但预览阶段应并行验证工具兼容：[Progress on TypeScript 7](https://devblogs.microsoft.com/typescript/progress-on-typescript-7-december-2025/)。
- TS 6 的 `types` 默认变为 `[]`，环境全局类型必须显式声明；这对 monorepo 隔离是好事，也会暴露依赖隐式全局的旧项目。
- 现代模块/ESM 与严格性成为默认方向。课程不以 ES5/AMD/UMD 旧生态作为新项目基线。

## 四、“高级 TypeScript”不是什么

- 不是能手写无限递归 `DeepWhatever<T>`；
- 不是业务代码零 `as`/零 `any` 的形式主义；
- 不是让每个调用者显式传 5 个泛型参数；
- 不是用类型假装验证了网络 JSON；
- 不是把所有字符串都 Brand 化；
- 不是一个 `tsconfig` 复制到浏览器、Node、测试、脚本所有环境。

高级能力是：在正确边界花正确复杂度，让调用端自然推断、错误可读、运行时安全、编译可承受、版本可升级。

## 五、课程如何产生岗位证据

招聘写“精通 TS”，你提交：领域状态机、Schema 边界、无断言公共 API、类型负例测试。  
招聘写“工程化”，你提交：配置矩阵、project references、构建 trace、性能改进和 CI 门禁。  
招聘写“架构设计”，你提交：SDK exports/声明兼容、模块边界、迁移 ADR、灰度回滚。  
招聘写“AI 能力”，你提交：对 AI 生成类型的审查规则、Schema 验证与安全流协议，而不只是“用过 Copilot”。

## 六、等级定义

- 完成 01–10：能可靠完成中型业务类型建模。
- 完成 01–17：有高级 TS 工程师的知识结构和迁移能力。

- 真实资深/专家：还需生产规模的 SDK 兼容、monorepo 性能、跨团队迁移、事故与组织影响，文稿不能代替。
