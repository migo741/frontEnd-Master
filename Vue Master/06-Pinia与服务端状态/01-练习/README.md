# 练习：状态归属与缓存失效

## 题 1（45 分钟）

为 OpsBoard 的“工单列表”给 12 个状态归属：当前用户、租户、分页、筛选、表格列宽、当前 hover 行、工单列表、工单详情、未提交编辑草稿、toast、权限集合、WebSocket 连接。输出表格：owner、生命周期、持久化、失效方式。允许一个状态有多层表示，但必须指定单一真相源。

## 题 2（60 分钟）

设计列表/详情缓存 key 和 mutation 后失效策略。场景：列表有租户、状态、负责人、分页；详情编辑成功；WebSocket 推送某工单变更。要求避免全量刷新，又不能显示已知过期数据。说明 optimistic update 的回滚策略。
