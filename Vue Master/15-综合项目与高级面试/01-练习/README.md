# 练习：毕业项目与答辩

## 题 1（2 周）

实现 OpsBoard 垂直切片。第一周先交 RFC、风险清单、测试计划和性能基线，再写代码；第二周完成、测量、修复与发布说明。限制：页面不超过 3 个，核心功能必须完整；不得用 UI 框架掩盖状态与交互问题。

验收脚本：刷新受保护深链；快速切换 5 次筛选；模拟并发 401；模拟 409；断网重试；键盘完成转派；重复进入退出详情检查 listener/内存；生产构建通过预算。

## 题 2（90 分钟）

完成一次闭卷模拟面试：

1. 手画 Vue 状态写入到 DOM 更新链路。
2. 设计 10 万行实时表格，给性能证据计划。
3. 解释 Pinia 与 server cache 的边界。
4. 设计动态权限与深链启动流程。
5. Code review 一段竞态请求。
6. 决策 SSR、SPA、微前端是否需要。

每题限 10 分钟回答，余下 30 分钟重听录音，标记没有证据、没有取舍、概念混用的句子。
