# 第 15 章：综合项目与高级面试

## 毕业项目：OpsBoard 企业运营工作台

目标不是再做一个 CRUD 后台，而是证明你能负责生产模块。产品范围：多租户登录与能力权限；工单列表/详情/编辑；URL 筛选；实时变更；远程成员 Combobox；审计日志；错误恢复。只做一个垂直切片，但要做深。

## 必须提交的工程证据

1. 一页架构图与 3 份 ADR：状态归属、数据加载、是否需要微前端。
2. strict TypeScript，API schema → DTO → domain；关键非法状态用 union 消除。
3. latest-wins 搜索、single-flight refresh、409 冲突恢复。
4. 权限后端兜底的说明，前端 capability 控制；富文本安全方案。
5. 单元/组件/集成/E2E 分层；关键路径不依赖脆弱 sleep。
6. 性能前后 trace、bundle budget、Web Vitals；一个真实问题的监控闭环。
7. CI 门禁、发布/回滚说明、README 一键启动。

## 评分（100）

- 正确性与异常恢复 20；架构和边界 20；类型与可维护性 15；测试 15；性能与可观测性 15；安全与 a11y 10；文档表达 5。
- 任何 token 泄露、前端替代后端授权、跨请求状态泄漏，直接判安全项不及格。
- 80 分是高级线；90 分以上要求有量化证据、清楚反证和优秀开发者体验。

## 高级面试的回答结构

用“场景与约束 → 候选方案 → 决策 → 失败模式 → 数据验证 → 复盘”回答。不要只背结论。被问 Vue 原理时从可观察现象走到内部机制，再回到工程决策；被问项目时讲你做出的判断和结果，不把团队成果全部说成个人。

## 持续学习

每季度抽样岗位与官方 release；每月读一个 Vue/Router/Pinia/Vite 的真实 issue 或 PR；把学习变成 ADR、测试或 benchmark。高级不是知道所有答案，而是能快速构造证据、控制风险并把方案讲清。
