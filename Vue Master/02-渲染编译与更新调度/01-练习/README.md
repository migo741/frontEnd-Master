# 练习：列表身份事故与渲染诊断

## 题 1（40 分钟）

一个可编辑表格用索引作 key。编辑第二行但未保存，然后按价格排序，输入内容跳到了另一商品。请：画出排序前后 VNode 身份映射；给出修复；解释改成 `:key="Math.random()"` 为什么更糟；写一个组件测试复现问题。

## 题 2（45 分钟）

10,000 行列表中，点击选中行时所有 `Row` 都执行 render。只允许做三处改动，要求：保持组件拆分；不引入全局 store；给出如何使用 Vue Devtools/Performance 面板证明优化有效。额外思考：虚拟列表解决的是什么成本，不能解决什么？
