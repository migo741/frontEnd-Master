# 半年章节阅读指南｜Vue Master 新版

> 半年并行预算仍为 **55 小时**。20 章全文深学需要约 185～240 小时，所以本页给出的不是“全文速读”，而是一条有明确取舍的高级能力快线。若 Vue 是唯一主攻方向，请走 README 中的完整深学线。

等级规则：

- `A`：高级开发必学，必须留下实现、测试或 profile 证据；
- `B`：优先学习，必须讲清机制和事故诊断，完整工程按产品需要；
- `C`：建立决策边界，真实需求出现后再实现。

## 快线执行规则

每个 A 级章节按以下方式压缩：

1. 读讲义中的事故、核心模型、生产边界和速记；
2. 两道练习都先做设计，至少完整实现其中一道；
3. 未实现题必须精读答案，并关闭答案复写关键路径；
4. 把证据合并到半年统一项目，不另建 20 个玩具仓库；
5. 讲义中的源码扩展、第二实现和全部发散题放入 D+30 复习池。

B/C 级章节不等于不重要，只是当前半年目标下按条件裁剪。

第 03 章也可提前与第 01 章并行；第 09 章里的 typecheck、lint、architecture test 应逐步贯穿所有练习，而不是等到第九章才第一次配置。

## 最低高级证据包

55 小时结束时，目录或统一项目里至少能找到：

- `reactivity-and-rendering.md`：从状态写入到 DOM commit 的因果链；
- `use-latest-task.ts` + tests：取消、乱序、卸载；
- 一个 strict typed SFC 公共契约；
- 一个有 focus/keyboard/ARIA 测试的 headless 组件；
- `state-ownership.md`：URL/Pinia/server/local/ephemeral 所有权；
- Router 权限与数据时序测试；
- 运行时 API schema + 401/security 用例；
- Vite/包边界 CI 规则；
- 测试风险矩阵；
- 性能/内存 before-after 报告；
- SSR/hydration 诊断记录；
- 固定版本组件实例、响应式与 renderer 调用链；
- keyed diff/LIS 手算与 scheduler phase 测试；
- Router/Pinia 并发请求隔离测试；
- 综合项目答辩材料。

## 落后时怎样降级

按这个顺序减少工作量：

1. 第 14 章只读讲义的成本模型与答案的 ADR；
2. 第 13 章不写 styled shell，只保留 headless 状态机和 a11y 测试；
3. 第 12 章只做 mismatch 与请求隔离实验；
4. 各章发散题移入 D+30；
5. 每章第二种实现不写，但必须读懂取舍和最小反例。

不要取消 01、04、06～11、15～17 和 19；它们构成“正确性 → 工程质量 → Vue Core → 可验证交付”的主链。

## 如果 Vue 成为求职主攻方向

半年结束后追加 130～185 小时走深学线：补齐所有未实现题、五章固定版本源码实验、Nuxt 实作、Design System 演进和迁移实验。追加学习仍应落在一个真实产品或长期项目中，不回到互不相干的 Demo 集合。
