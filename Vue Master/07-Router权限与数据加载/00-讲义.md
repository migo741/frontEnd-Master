# 第 07 章：Router、权限与数据加载

## 路由是应用状态与安全边界的一部分

路由定义 URL、模块加载、数据预取、访问控制和错误恢复。把所有逻辑塞进一个全局 `beforeEach` 会形成不可测的“上帝守卫”。按职责拆为认证、租户、能力检查、标题/埋点，且每个 guard 返回明确结果，不混用旧式 `next()`。

## 权限模型

前端权限只能改善体验，不能提供真正安全；后端必须再次授权。前端使用 capability/permission（如 `ticket:update`），不要在各处硬编码 role === admin。路由 meta 应类型化，菜单由可访问路由派生，避免菜单和路由两套权限表漂移。

动态路由要处理：权限未加载时等待一次、刷新深链、退出后 removeRoute、租户切换、404 区分“无匹配”和“尚未注入”。`router.isReady()` 后再挂载可减少首屏跳转闪烁。

## 数据加载的两个有效模型

导航后加载：页面快速切换，展示 skeleton，适合非关键数据。导航前加载：数据准备好再确认导航，适合没有数据就不能进入的页面。两者都要取消旧导航请求、处理错误并防瀑布。Vue Router 的 Data Loaders 在调研时仍包含 experimental API，课程理解模式但不把实验接口作为生产标准。

## URL 是可恢复状态

筛选、排序、分页应从 route query 派生，并做 parser/serializer。不要直接信任 `route.query.page as string`；它可能是数组、空值或非法数字。规范化后必要时 replace URL。
