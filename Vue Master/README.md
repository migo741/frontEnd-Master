# Vue Master：从“会写 Vue”到“能负责 Vue 系统”

> 调研快照：2026-09-02  
> 生产学习基线：Vue 3.5.42、TypeScript strict、Vue Router 5.3.0、Pinia 4.0.3、Vite 8.2.2、Vitest、Vue Test Utils、Playwright；Nuxt 4 用于 SSR/全栈渲染。  
> Vue 3.6 仍为 RC，Vapor Mode 只放在第 14 章作为前沿观察，不作为毕业项目默认依赖。

这是一套面向已经具备 Vue 3 中级能力的高级课程。它不再花大量篇幅解释 `v-if`、`v-for` 或如何发起一个普通请求，而是训练下面这件事：

> 面对复杂业务、异步竞态、类型边界、线上性能、SSR、一致性和多人协作时，能建立正确模型，拿出可验证方案，并为结果负责。

## 新版与旧版的差别

原 15 章覆盖的是“高级 Vue 应用工程”，但组件实例、真实响应式实现、SFC compiler、renderer/scheduler 和生态源码还不够显式。新版保留原 15 章生产主线，并新增 16～20 五章 Vue Core 深入主线；每章仍固定三个入口：

- `00-讲义.md`：从事故或真实需求出发，定义术语，逐层推导机制，并给出生产边界和可运行核心示例；
- `01-练习/README.md`：每章固定两题，一道验证底层模型，一道贴近生产环境；
- `02-答案/README.md`：不仅给代码，还解释契约、取舍、测试、常见错解和系统边界。

新版不是“API 更多”，而是证据更完整。遇到看不懂的段落时，可以把该小节连同前后的“术语”和“上下文”一起交给 AI 追问；文档刻意保留了足够的因果链，不依赖一句含糊口诀。

## 开始前先读什么

1. 先读 [`00-课程总索引.md`](./00-课程总索引.md)，理解 20 章怎样组成“生产工程 + Vue Core”两条互相验证的主线。
2. 再读 [`00-版本策略与一手资料.md`](./00-版本策略与一手资料.md)，知道哪些是稳定基线，哪些只能渐进采用。
3. 如果你在执行半年总路线，按 [`00-半年章节阅读指南.md`](./00-半年章节阅读指南.md) 的 55 小时快线学习。
4. 若目标明确是 Vue 3 高级开发，走完整深学线；预计 185～240 小时，取决于源码实验和毕业项目复用程度。
5. 每章用 [`学习记录模板.md`](./学习记录模板.md) 留下自己的失败证据与复写记录。

## 每章固定学习闭环

```text
讲义：建立模型
  ↓ 先不看答案
练习：暴露错误假设
  ↓ 保留第一次方案与失败证据
答案：对照契约、实现、测试与边界
  ↓ 关闭答案
复写：重新实现关键路径 + 写一页取舍说明
  ↓
迁移：在自己的项目里找一个同类问题
```

建议限时不是为了催促，而是防止无效卡死：

- 读讲义后必须能写出 5～10 行自己的因果链；
- 练习独立思考至少 30 分钟，通常不超过 90 分钟后开始分级看答案；
- 看答案时先比“契约和不变量”，再比代码；
- 第二天关闭答案复写关键路径；
- 第七天只看题面重做一遍，并补一个最小反例。

## 两条学习路线

### 半年并行快线：55 小时

适合你还要同步学习 JavaScript、TypeScript、CSS、数据结构、后端和架构。这里的“55 小时”不是把每个答案全部敲完，而是：

- A 级章节完成讲义核心段、两题设计和至少一道完整实现；
- B 级章节完成机制图、事故诊断与关键测试；
- C 级章节先形成决策边界，真实项目需要时再实现；
- 第 15 章不另造孤立玩具项目，直接把证据落到半年统一项目；第 16～20 章至少完成三条真实调用链和两次源码驱动故障复现。

具体取舍见 `00-半年章节阅读指南.md`。

### Vue 主攻深学线：185～240 小时

适合准备 Vue 高级岗位、负责中大型 Vue 项目，或即将上线自己的 Vue SaaS。建议 18～24 周，每周 9～12 小时：

- 讲义、手算和最小实验：约 30%；
- 独立练习：约 30%；
- 对照答案、复写和测试：约 25%；
- 迁移到真实项目、复盘与口述：约 15%。

完整路线必须提交每章至少一项证据；“读完了”不是证据。

## 统一业务背景

课程使用一个连续背景：多租户运营工作台 `OpsBoard`。它有工单、权限、筛选 URL、离线草稿、实时事件、数据表格、管理后台和 SSR 落地页。连续背景的意义不是强迫你创建同名仓库，而是避免每章都写无上下文 Todo：

- 第 01～04 章解决响应式与异步资源正确性；
- 第 05～08 章定义 UI、状态、导航和网络边界；
- 第 09～12 章建立构建、测试、性能与渲染质量；
- 第 13～15 章处理平台化、架构演进和最终交付。
- 第 16～20 章回到固定版本真实源码，把组件、响应式、compiler、renderer、Router 与 Pinia 的机制连接到前面出现的生产事故。

你可以把全部题目映射到自己的项目；只要保留题目的契约、规模和故障条件即可。

## 毕业不是会背 API

完成课程后，至少应拿出这些可复核证据：

- 一张从响应式写入到 DOM commit 的链路图，并能用最小复现解释 `flush`、`nextTick` 与外部 Promise；
- 一个可取消、可测试、生命周期所有权正确的 composable；
- 一个有键盘、焦点、ARIA 和异步状态测试的无头复杂组件；
- 一份状态所有权图，区分 URL、Pinia、server state、本地草稿与连接对象；
- 一条包含运行时 schema、鉴权刷新、错误恢复和幂等策略的 API 链路；
- 一套单元/组件/集成/E2E 合理分工的测试证据；
- 一份有基线、profile、改动和回归阈值的性能/内存报告；
- 一次 SSR/hydration 故障诊断和跨请求污染测试；
- 三张固定版本源码调用链图：组件实例、响应式、compiler/renderer；
- 一次 keyed diff 手算与组件状态保持测试，以及一次 Router/Pinia 并发请求隔离实验；
- 两页以内的 ADR，能说明边界、替代方案、风险和回滚条件；
- 一个可运行、可演示、可部署、能回答追问的综合项目切片。

## 本课明确不做什么

- 不把手写 `reactive()` 当作工作日常；它用于建立排障模型。
- 不把 Pinia 当所有状态的默认归宿，也不把前端 RBAC 当真正授权。
- 不用快照数量冒充测试质量，不用 Lighthouse 单次高分冒充真实性能。
- 不为了“高级”默认上微前端、Monorepo、SSR 或实验编译模式。
- 不把 Vue 3.6 RC/Vapor 写成当前稳定基线；正式升级必须重新做兼容和基准验证。
- 不逐行背源码，也不让业务代码导入 Vue 私有模块；源码用于建立因果模型、复现故障和验证升级。
- 不把课程答案当唯一正确架构。生产题允许多解，但必须能说明契约、数据规模、失败语义和验证证据。

## 与其他 Master 的边界

- JavaScript/浏览器：事件循环、Promise、DOM、网络、内存和 Worker 在 JavaScript Master 深学；本课只解释它们如何改变 Vue 行为。
- TypeScript：类型系统原理在 TS Master 深学；本课专注 Vue SFC 和组件公开契约。
- CSS/UI：布局、级联、动效和视觉工程在 CSS Master 深学；本课专注组件状态、语义和 Vue 绑定边界。
- DSA：LIS、LRU、图和缓存结构在 DSA Master 深学；本课说明 Vue diff、KeepAlive 和依赖图中的生产映射。
- Backend：鉴权、缓存、数据库和分布式一致性在 Backend Master 深学；本课坚持前后端契约与信任边界。
- Frontend Architecture：组织级架构方法在 Architecture Master 深学；本课把约束落到 Vue 包、路由和组件上。

你最终要获得的不是“Vue 专用技巧集合”，而是借 Vue 训练一套可以迁移到其他 UI 框架的软件工程能力。
