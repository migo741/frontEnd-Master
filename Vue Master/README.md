# Vue Master：从 Vue 3 中级到高级工程师

> 调研基线：2026-08-30；稳定学习基线：Vue 3.5.x + TypeScript + Vite。Vue 3.6 当日仍处于 RC，列入观察项，不把候选 API 当生产必修。

这不是 API 百科，也不是题库。它是一条以企业级「运营工作台 OpsBoard」为连续业务背景的进阶路线：每章只保留 2～3 道能暴露真实能力差距的题。你可以做不出来，但必须在看答案前留下自己的设计和失败记录。

## 先这样使用

每章严格只有三个入口：

1. 先读 `00-讲义.md`，完成其中的“自检”。
2. 再进入 `01-练习/README.md`，限时独立完成；卡住 45 分钟可看一级提示。
3. 最后进入 `02-答案/README.md`，不要只读：关闭答案后再默写一次关键实现，并写一段取舍说明。

根目录文档不属于章节：`README.md` 是导航，`00-市场调研与能力地图.md` 解释为什么学这些，`学习记录模板.md` 用于复盘。

## 15 章路线

| 阶段 | 章节 | 交付能力 |
|---|---|---|
| 内核 | 01 响应式心智模型 | 能解释依赖收集、调度、清理与常见失效 |

## 推荐节奏（16 周）

- 第 1～4 周：01～04，每周一章。
- 第 5～8 周：05～08，每周一章。
- 第 9～12 周：09～12，每周一章。
- 第 13～14 周：13～14。
- 第 15～16 周：15 章毕业项目、复盘和模拟面试。

每周建议 8～12 小时：讲义 20%，独立练习 45%，对照与重构 25%，复盘 10%。不要为了赶周数跳过测试和复盘。

## 毕业标准

最终不是“看完”，而是下面 6 项同时成立：

- 能在 30 分钟内讲清 Vue 响应式与渲染更新链路，并能用最小复现证明判断。
- 能为中大型项目划分模块、状态、API 与包边界，写出一页 ADR 说明取舍。
- 核心业务具备单元/组件/E2E 的合理测试组合，测试验证行为而非实现细节。
- 用 Lighthouse/Web Vitals/Performance/Memory 数据给出优化前后对比。
- 能独立完成动态权限、错误恢复、并发请求治理、灰度与监控闭环。
- 毕业项目总评至少 80/100，且“安全、正确性、可维护性”任一项不低于 12/20。

## 版本与资料策略

代码示例默认使用 `<script setup lang="ts">`、Composition API 和 strict TypeScript。不要盲目追最新版：稳定版用于练习，RC/实验 API 只记录设计方向。每季度重新核对根目录调研文档中的官方 release、Vue Router、Pinia、Vite、Nuxt 和测试工具链接。
