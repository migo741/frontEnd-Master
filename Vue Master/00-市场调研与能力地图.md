# 2026 国内 Vue 3 高级岗位调研与能力地图

## 调研口径

基线日期为 2026-08-30。样本包含近期国内招聘页、企业招聘页及 Vue 官方生态资料。招聘描述会过期，也会混入“愿望清单”，因此课程不按单条 JD 逐字教学，而是抽取多个来源反复出现、且能被作品验证的能力。

## 市场信号

近期 Vue 3 岗位反复出现的硬技能组合是：TypeScript、Composition API、Pinia、Vue Router、Vite、组件化、性能优化与工程规范。更高级的岗位开始要求设计系统、Vitest/MSW/Playwright 测试分层、OpenAPI 类型安全、Sentry/Lighthouse 监控、CI/CD、SSR/微前端/多端经验，以及能独立负责复杂模块和技术方案。

大厂/高阶岗位的框架表述往往反而更宽：Vue/React 只是入口，真正看重 JavaScript/TypeScript 基础、抽象与模块设计、复杂问题定位、性能兼容性、产品意识、跨团队交付与技术影响力。因此本课程不会把“会更多 Vue API”误当高级。

## 能力分层

| 层级 | 典型表现 | 本课程的验证方式 |
|---|---|---|
| 中级 | 能独立 CRUD、配置路由与 store | 不再重复基础语法 |
| 高级编码 | 类型严谨、异步正确、抽象适度 | 01～08 章典例与 code review |
| 高级工程 | 测试、构建、性能、安全形成门禁 | 09～12 章可测交付物 |
| 高级设计 | 能定义边界、权衡方案、推动迁移 | 13～15 章 ADR 与毕业答辩 |

## 岗位要求到章节的映射

- Vue 3 原理、复杂组件：01、02、05、13。
- TypeScript 中大型项目经验：03、08、09。
- Pinia、Router、权限、接口联调：06～08。
- Vite/Webpack、模块化、规范、Git/CI：09、14、15。
- 单元/集成/E2E 测试：10。
- Web Vitals、性能与线上问题：11、14。
- SSR/Nuxt、多端、微前端：12、14。
- 从零到一、方案评审、文档与沟通：15。
- React 只作为对照心智模型，不扩展为第二套课程；高级前端应能识别 hooks/composables、signals/refs、server state 等共同问题。

## 与时俱进的维护规则

每季度只做三件事：检查 Vue 稳定版和破坏性变更；抽样 10 条目标城市/职级的真实 JD，统计重复关键词；检查毕业项目的依赖、Web Vitals 与安全告警。新工具只有在“岗位重复出现 + 官方稳定 + 能解决现有痛点”至少满足两项时，才进入必修。
