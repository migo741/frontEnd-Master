# 半年章节阅读指南｜React Master

> 本课预算：32 小时。你的主框架仍是 Vue；本轮目标是建立可靠 React 心智模型、能维护真实项目并看懂高级方案，不与 Vue 路线竞争“第二主栈专家”的时间。

等级规则：`A` 是跨框架高级开发必须掌握的 React 机制；`B` 是优先补齐的常见工程能力；`C` 是特定技术路线或与其他 Master 重复，本轮快读。

## 本课通过标准

- 不把组件函数理解成长驻实例；
- 不用 Effect 编排本可由事件、派生值、router 或 query 表达的流程；
- 能分清 URL、server state、表单、局部状态与跨树客户端状态；
- 能写确定性竞态测试、错误边界与性能证据；
- 能独立修改一个 TypeScript React 业务模块，而不要求在半年内成为 Next.js/RSC 专家。
