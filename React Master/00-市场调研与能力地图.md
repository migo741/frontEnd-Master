## 二、官方生态变化决定“不学什么”

- React 官方版本页在调研日标明最新文档线为 **19.2**：[React Versions](https://react.dev/versions)。
- React 官方已在 2025-02 弃用 Create React App，新项目建议使用框架，或 Vite/Parcel/Rsbuild 等构建工具：[Sunsetting Create React App](https://react.dev/blog/2025/02/14/sunsetting-create-react-app)。
- React Compiler 1.0 已稳定，不应再把“到处手写 `useMemo`/`useCallback`”当作高级 React 的证明；仍需会测量和理解引用稳定性：[React Compiler v1.0](https://react.dev/blog/2025/10/07/react-compiler-1)。
- React 19.2 引入 `Activity`、`useEffectEvent`、性能轨道等能力，但企业代码仍存在 React 18，因此课程采用双版本理解：[React 19.2](https://react.dev/blog/2025/10/01/react-19-2)。
- RSC 在 2025–2026 出现过严重安全公告，使用 Server Components/Functions 时不能只会功能，不会补丁与信任边界：[RSC 安全公告](https://react.dev/blog/2025/12/03/critical-security-vulnerability-in-react-server-components)。

由此，本课程不把以下内容作为主线：类组件生命周期背诵、字符串 ref、旧 Context、`ReactDOM.render`、手写传统 Redux 样板、CRA、Enzyme、无测量的 memo 化。遇到遗留项目时按迁移资料补读即可。

## 四、课程如何把“岗位词”变成可验证能力

招聘描述常写“熟悉性能优化”。本课程要求你提交：性能假设、基线 profile、变更、对比数据和回归测试。  
招聘描述常写“熟悉状态管理”。本课程要求你先给每份状态分类，再解释为什么某份数据不应该进入 Redux。  
招聘描述常写“深入理解 React”。本课程要求你用快照、闭包、Fiber、lane、render/commit 解释真实 bug。  
招聘描述常写“工程化”。本课程要求你写出可执行的 CI 门禁、模块边界和升级策略。  
招聘描述常写“架构能力”。本课程要求你输出 ADR、容量估计、故障域、灰度回滚与演进路线，而不只是画盒子。

## 五、目标等级定义

### 学完但没有完整项目：合格中级

能独立实现复杂功能、测试和排错，知道主要取舍。

### 学完并完成第 18 章项目：高级候选人

能展示架构、性能、可靠性、安全和协作证据；面试中能把原理落到项目决策。

### 再叠加真实规模与组织影响：资深/专家

需要在生产中处理流量、故障、迁移、跨团队推进、人才培养和长期演进。课程给你方法与模拟场景，但这些证据必须由真实工作补齐。
