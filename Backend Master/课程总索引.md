# Backend Master 课程总索引

> 打勾标准不是“看过”，而是已合上答案复写、通过验收，并把关键模式合入统一项目。

## 使用说明

每章记录五个状态：

```text
[ ] 讲义与自检
[ ] 练习 1
[ ] 练习 2
[ ] 合上答案复写
[ ] 合入项目并留下证据
```

课程总量：22 章、44 道精选练习、6 个阶段门禁、1 个统一毕业项目。

## 第一阶段：运行时与服务边界

- [ ] [01 Node 运行时、进程与资源生命周期](./01-Node运行时进程与资源生命周期/00-讲义.md)  
  证据：异步资源 LIFO/幂等关闭测试、SIGTERM 排空与强制截止测试。
- [ ] [02 网络、反向代理与 HTTP 语义](./02-网络反向代理与HTTP语义/00-讲义.md)  
  证据：ETag 条件请求测试、可信代理与慢请求攻击测试。
- [ ] [03 TS 服务架构、配置与运行时边界](./03-TS服务架构配置与运行时边界/00-讲义.md)  
  证据：依赖方向测试、监听端口前 fail-fast 的配置测试。

### 阶段门禁 A

- [ ] 服务能正确启动、关联请求、限制资源、处理错误并优雅关闭。
- [ ] 领域层不依赖 Fastify、NestJS、ORM 或环境变量。

## 第二阶段：PostgreSQL 与数据权威

- [ ] [04 关系建模、约束与租户数据](./04-PostgreSQL关系建模约束与租户数据/00-讲义.md)  
  证据：DDL、约束矩阵、并发重复写入测试。
- [ ] [05 SQL、索引、执行计划与稳定分页](./05-SQL索引执行计划与稳定分页/00-讲义.md)  
  证据：游标分页并发测试、优化前后 `EXPLAIN (ANALYZE, BUFFERS)`。
- [ ] [06 事务、隔离、锁与并发控制](./06-事务隔离锁与并发控制/00-讲义.md)  
  证据：无负余额且无死锁转账、write skew 复现与 Serializable 修复。
- [ ] [07 Schema 演进、迁移与恢复](./07-Schema演进迁移与恢复/00-讲义.md)  
  证据：expand/contract 回滚、断点 backfill、恢复校验。

### 阶段门禁 B

- [ ] 永远不能为假的事实已由数据库约束。
- [ ] 备份已在空环境恢复，并通过数据与业务不变量校验。

## 第三阶段：SaaS 业务边界

- [ ] [08 身份认证、Session 与 OIDC](./08-身份认证Session与OIDC/00-讲义.md)  
  证据：会话固定、CSRF、回调重放和撤销测试。
- [ ] [09 授权策略与多租户隔离](./09-授权策略与多租户隔离/00-讲义.md)  
  证据：授权矩阵、IDOR/跨租户攻击、RLS 纵深测试。
- [ ] [10 API 契约、演进与幂等](./10-API契约演进与幂等/00-讲义.md)  
  证据：消费者契约、并发 Idempotency-Key、payload 冲突测试。
- [ ] [11 文件、对象存储、Webhook 与第三方边界](./11-文件对象存储Webhook与第三方边界/00-讲义.md)  
  证据：直传 finalize 安全测试、Webhook 验签与重放测试。

### 阶段门禁 C

- [ ] 猜中任意对象、文件或任务 ID 都不能跨租户读写。
- [ ] 外部重复请求不会产生重复业务副作用。

## 第四阶段：异步、分布式与 Agent 边界

- [ ] [12 Redis 缓存、限流与协同](./12-Redis缓存限流与协同/00-讲义.md)  
  证据：缓存竞态测试、原子限流与 Redis 故障策略。
- [ ] [13 队列、后台任务与可恢复状态机](./13-队列后台任务与可恢复状态机/00-讲义.md)  
  证据：worker 崩溃、重复投递、DLQ、generation fencing 测试。
- [ ] [14 Outbox、Inbox、Saga 与跨系统一致性](./14-Outbox-Inbox-Saga与跨系统一致性/00-讲义.md)  
  证据：提交后崩溃与重复发布测试、补偿审计。
- [ ] [15 超时、重试、熔断、隔舱与过载保护](./15-超时重试熔断隔舱与过载保护/00-讲义.md)  
  证据：共享 deadline、full jitter、故障注入和无重试风暴证明。
- [ ] [16 SSE、实时事件、背压与断线恢复](./16-SSE实时事件背压与断线恢复/00-讲义.md)  
  证据：Last-Event-ID 重放、慢消费者、取消与迟到事件测试。
- [ ] [17 Node 与 Python Agent 的信任边界](./17-Node与Python-Agent信任边界/00-讲义.md)  
  证据：双向契约、旧 worker、毒消息、HITL 参数绑定与幂等执行。

### 阶段门禁 D

- [ ] 关闭 worker、Redis 或模型供应商后，业务事实不丢、不重复、不错租户。
- [ ] Agent 无法绕过 Node 的授权、审批、额度和审计。

## 第五阶段：生产质量与交付

- [ ] [18 后端安全、秘密与 Agent 攻击面](./18-后端安全秘密与Agent攻击面/00-讲义.md)  
  证据：SSRF / DNS rebinding / body bomb 测试、工具沙箱与 prompt injection 红队。
- [ ] [19 测试、契约与故障验证](./19-测试契约与故障验证/00-讲义.md)  
  证据：真实依赖集成测试、重复/乱序/重启/超时联合故障测试。
- [ ] [20 日志、Metrics、Trace、SLO 与容量工程](./20-日志Metrics-Trace-SLO与容量工程/00-讲义.md)  
  证据：端到端脱敏 trace、SLI/SLO、容量拐点与 burn-rate 告警。
- [ ] [21 容器、CI/CD、云发布与灾难恢复](./21-容器CI-CD云发布与灾难恢复/00-讲义.md)  
  证据：不可变镜像、兼容迁移、灰度回滚、RTO/RPO 恢复演练。

### 阶段门禁 E

- [ ] 从空环境可重复部署同一不可变制品。
- [ ] 系统可观测、可压测、可灰度、可回滚、可恢复。

## 第六阶段：统一毕业项目

- [ ] [22 多租户 AI 工单与运营工作台](./22-毕业项目系统设计与面试/00-讲义.md)  
  黄金链路：创建工单 → 上传附件 → 启动 Agent → SSE 流式投影 → Tool Intent → 人工批准 → 幂等执行 → 审计。  
  红队链路：跨租户攻击、重复消息、worker 崩溃、模型超时、慢 SQL、发布回滚和数据恢复。

### 最终门禁

- [ ] 44 题均保留独立尝试、参考复写和变式测试。
- [ ] README 能让陌生人从空环境复现黄金链路。
- [ ] 有 ER 图、威胁模型、授权矩阵、核心状态机和部署图。
- [ ] 有 SQL plan、端到端 trace、容量报告和成本说明。
- [ ] 有 ADR、runbook、恢复记录和事故复盘。
- [ ] 有 10 分钟演示视频与 45 分钟系统设计答辩稿。
- [ ] 能现场改变一个需求，并解释数据、兼容、故障和发布影响。

## 季度复盘

每 12 周回答一次：

1. 哪个不变量已由代码和数据层共同保证？
2. 哪次失败实验改变了你的设计？
3. 哪项证据能放进简历并接受追问？
4. 哪个组件只是“用过”，尚未证明理解？
5. 下一季度应补深度，还是继续扩技术名词？

若第三问没有具体答案，暂停新章节，把最近四章合回毕业项目。
